# Hermes Android

Hermes 是面向个人自部署 Hermes Agent 的轻量安卓客户端。模型、Skills、工具和记忆继续在服务器运行，手机端提供日常聊天、会话和附件入口。

当前版本：`3.0.0-release`（统一体验与连续语音声能核心）

> 升级说明：v0.3.1 起使用随工程保存的固定开发签名。已经安装 v0.3.1–v2.8.1 的手机可以直接覆盖安装 v3.0.0；更早版本仍需先卸载一次。

## 已实现

- 与 Hermes Desktop 相同的远程网关连接方式
- 远程 URL + Hermes 用户名和密码登录
- 登录 Cookie 的 Android Keystore 加密存储与自动续期
- 从会话页切换 Hermes Profile；选择会保存到本机，会话、设置、项目和任务请求均按 Profile 隔离
- 未发送文字草稿按 Profile 和会话自动保存；发送失败恢复文字与附件并支持一键重新发送
- 会话页顶部支持切换当前 Profile；筛选栏支持切换最近/项目视图，并按项目和时间范围筛选
- 会话列表、新建会话、继续会话、删除、归档与置顶会话；列表项支持左滑露出归档和删除操作
- 单个会话 AI 重命名，会话标题最多显示 15 个字符
- Hermes 原生项目视图、服务器目录选择式新建项目与“移至项目”操作
- 统一采用 Telegram 式清爽办公界面：浅灰页面、白色分组表面、平铺列表、克制圆角和单一交互蓝
- 支持浅色、深色、跟随系统三种颜色模式；升级后自动收敛旧版清爽办公/液态玻璃皮肤偏好
- UI 2.5 在 Telegram 式个人主页上补齐 Memory / Soul 核心入口、头像连续形状过渡、会话左滑操作与更克制的全局点击反馈；Memory / Soul 会直接打开当前 Profile 的原始 Markdown 文件
- Telegram 风格图标系统第一轮：底栏使用线性/实体双态图标并平滑过渡，首页、聊天、助理面板、个人主页、Memory / Soul 与设置入口统一为 24 × 24 圆润轻量矢量；设置页保留高辨识度语义色底板
- 首页头像、搜索及紧凑的全宽“最近 / 项目”切换区域固定显示
- 标题左侧黄色置顶标识
- 首页右上角搜索入口、右下角悬浮新对话按钮与独立会话搜索页
- 对话搜索可检索最近 100 个会话、每个会话最近 200 条消息正文，并定位到命中消息
- 对话列表下拉刷新，以及小标题、舒展留白的高辨识度会话列表
- 会话真实摘要与中文相对时间；Cron 会话不进入普通对话列表，统一在任务执行中心查看
- TUI Gateway JSON-RPC / WebSocket 流式回复
- 实时流长时间静默时自动核对服务端会话并同步已完成回复；断线后延长取回窗口，审批和澄清请求可跨进程恢复后继续
- Agent 运行期间全局展示当前阶段；支持追加要求、排队发送以及直接处理审批/澄清请求
- 本轮完成后只显示与助手正文左对齐的轻量完成状态，不再重复回复正文；系统通知可直达对应 Profile、对话或任务页
- 返回会话列表后流式回复继续在应用内生成；完成后发送系统通知，并以会话未读红点提示尚未查看的回复
- 输入区提供独立 `/` 按钮与可搜索、分类浏览的命令面板；仍支持直接输入 `/` 动态筛选，兼容内置、快捷与技能命令
- 一次性专家会审移入聊天右上角助理面板：深度模式使用真实 `delegate_task` 子 Agent，快速模式使用 Hermes MoA；仅展示压缩后的共识、分歧、证据、风险与裁决
- 助手回复使用全宽文档式排版；用户消息显示本机头像、昵称与紧凑气泡，提升身份辨识与 Markdown 阅读宽度
- 本机用户可选择并裁剪头像，图片会复制到应用私有目录；Hermes 使用内置头像，本机可分别设置双方聊天昵称
- 工具执行状态摘要、停止生成；原始工具与系统输出不会混入聊天气泡
- 当前会话模型切换、聊天产物与 Hermes 待办汇总面板
- 会话标题沿用 Hermes 异步自动总结并限制为 15 个字符
- 普通聊天首屏只读取最近 60 条并支持向上翻页；搜索保持最近 200 条覆盖，兼顾进入速度与定位能力
- 流式回复按帧合并更新，完成后再渲染完整 Markdown；最近产物只增量扫描发生变化的会话
- 长会话离开底部后显示“跳到底部”，流式回复不会强行打断向上阅读
- 图片与常见文本附件
- 支持从安卓系统分享菜单把网页、文字、图片和常见文本发送到 Hermes，并选择新会话或最近会话继续处理
- 工作空间图片、聊天图片和待发送图片附件的 APP 内全屏缩放预览
- 聊天中的 `@image:/...` 与标准 Markdown 图片链接自动读取为内联缩略图；点击可全屏缩放查看
- 聊天输入框麦克风提供单次语音输入，识别后写入输入框或按设置自动发送；顶部波形按钮独立进入连续语音
- 沉浸式连续语音只展示通话状态，不重复堆叠文字对话；使用完整柔光环、玻璃层和真实音量声波组成的声能核心，支持 Agent STT/TTS、Android 回退、自动朗读与打断
- “我的 → 语音设置”可按当前 Profile 管理 STT/TTS 服务商、模型、识别语言和声音，并直接测试服务器识别与合成
- 中文语音转写默认统一为简体，可切换繁体或保持模型原文；单条输入、连续语音和测试共用同一设置
- Markdown 标题、分割线、任务列表、引用、紧凑代码块、固定列宽表格与图片的高密度排版预览
- 助手回复中的网页链接自动汇总为参考来源卡片，支持行内链接、引用式链接与普通 URL，并忽略代码块和图片地址
- 浅色、深色、跟随系统三种外观
- Hermes Light 会话图标、分区强调色、统一圆角弹层与飞书式聊天布局
- 输入框快捷面板：文件、图片、链接、项目空间与提示词片段；输入法弹出时输入框保持可见

## 首次连接

连接页填写：

```text
远程网关地址：http://你的服务器IP:9119
Hermes 用户名：与电脑端相同
Hermes 密码：与电脑端相同
```

地址就是 Hermes Desktop 设置里“远程 URL”的完整内容，不要添加 `/api`、`/v1` 或其他接口路径。反向代理使用路径前缀时，可以把前缀保留在地址中。

密码只在登录时使用，不会保存。APP 保存的是 Hermes 返回的登录 Cookie，并通过 Android Keystore 加密。网关会话仍有效时，后续启动可自动登录。

> 当前示例地址使用 HTTP，流量未加密。APP 为兼容现有网关允许用户明确确认后连接；建议后续改用 HTTPS，或只通过 Tailscale/WireGuard 等可信 VPN 访问。

详细说明见 [docs/SERVER_SETUP.md](docs/SERVER_SETUP.md)。

## 工程与构建

- JDK 17
- Android Gradle Plugin 8.13.2
- Gradle 8.13
- Kotlin 2.3.20
- Jetpack Compose BOM 2026.06.00
- Android 8.0+（`minSdk 26`）
- 本机存在 `signing/hermes-debug.keystore` 时使用固定测试签名；公开源码不包含该文件，缺失时自动使用 Android 默认 Debug 签名

用 Android Studio 打开项目根目录，等待 Gradle Sync 后运行 `app`。命令行构建：

```bash
./gradlew clean testDebugUnitTest assembleDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`

## 附件范围

- 图片：通过远程网关 `image.attach_bytes` 上传，单张不超过 8 MiB
- 文本：读取内容后随消息发送，单个不超过 512 KiB
- 单次最多 5 个附件

PDF、Word、Excel 原始文件和拍照压缩计划放入后续版本。
