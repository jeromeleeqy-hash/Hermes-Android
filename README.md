# Hermes Android

Hermes 是面向个人自部署 Hermes Agent 的轻量安卓客户端。模型、Skills、工具和记忆继续在服务器运行，手机端提供日常聊天、会话和附件入口。

当前版本：`3.6.5` 正式版（温暖首页人物对齐、小字号日期星期、48 组随机短句；同版本修订对话菜单尺寸）

本版说明见 [3.6.5 更新说明](docs/RELEASE-3.6.5.md)，English users: [Quick start](docs/QUICK-START-EN.md)。常见操作见应用内“我的 → 使用说明”或 [分级操作指南](docs/OPERATION-GUIDE.md)。

首页“跟我说”打开固定的普通 Hermes 日常对话；分享默认进入同一对话。移除 3.4.0 的分类收集、计划采用和独立助理资料同步，记忆、文件与定时任务沿用 Hermes 原有能力。保留可恢复的单次录音转写。无需安装新的服务器服务或配置专用 workspace。

助理首页、集中阅读视图和独立决策面板，配合「助理 / 回看 / 任务 / 文件 / 我的」五栏导航。点击“任务”直接进入执行中心。

> 安装说明：`Hermes-3.6.5.apk` 为不可调试的正式 Release 构建。为覆盖当前预览版并保留本机配置，发行包沿用原预览版的应用 ID 与签名；桌面名称为 Hermes，版本为 3.6.5。可直接覆盖同签名的 3.4.1–3.6.1 预览版和 3.6.2–3.6.4 正式版。源码不包含签名私钥。

热修说明与验收步骤见 [3.0.4a 修复说明](Hermes-v3.0.4a-release-notes.md)。

## 首次连接

首次进入播放约 5 秒的欢迎动画，可跳过。在“认识彼此”设置手机端助理昵称、头像和自己的称呼，然后进入网关连接页。升级用户保留资料，只展示一次新增动画；应用内使用说明可重看。

连接页填写：

```text
远程网关地址：http://你的服务器IP:9119
Hermes 用户名：与电脑端相同
Hermes 密码：与电脑端相同
```

地址就是 Hermes Desktop 设置里“远程 URL”的完整内容，不要添加 `/api`、`/v1` 或其他接口路径。反向代理使用路径前缀时，可以把前缀保留在地址中。

密码只在登录时使用，不会保存。APP 保存的是 Hermes 返回的登录 Cookie，并通过 Android Keystore 加密。网关会话仍有效时，后续启动可自动登录。

> 当前示例地址使用 HTTP，流量未加密。APP 为兼容现有网关允许用户明确确认后连接；建议后续改用 HTTPS，或只通过 Tailscale/WireGuard 等可信 VPN 访问。

详细说明见 [docs/SERVER_SETUP.md](docs/SERVER_SETUP.md)。

## 工程与构建

- JDK 21（玻璃依赖的 JVM 测试需要 Java 21；APP 仍输出 Java 17 目标字节码，由 Android 工具链转成 DEX）
- Android Gradle Plugin 8.13.2
- Gradle 8.13
- Kotlin 2.3.20
- Jetpack Compose BOM 2026.06.00
- Android 8.0+（`minSdk 26`）
- 本机存在 `signing/hermes-debug.keystore` 时使用固定测试签名；公开源码不包含该文件，缺失时自动使用 Android 默认 Debug 签名

用 Android Studio 打开项目根目录，等待 Gradle Sync 后运行 `app`。3.6.5 正式覆盖升级包构建命令（签名参数使用单独保存的原预览签名路径）：

```bash
./gradlew testDebugUnitTest assembleRelease -PhermesPreview=true -PhermesSigningFile=/absolute/path/hermes-preview.keystore
```

原测试应用 ID 的默认构建：

```bash
./gradlew clean testDebugUnitTest assembleDebug
```

正式 APK 输出：`app/build/outputs/apk/release/app-release.apk`；开发构建输出：`app/build/outputs/apk/debug/app-debug.apk`。`hermesPreview=true` 在正式构建中只沿用原预览包的应用 ID，不添加 Preview 名称或版本后缀。

## 附件范围

- 图片：通过远程网关 `image.attach_bytes` 上传，单张不超过 8 MiB
- 文本：读取内容后随消息发送，单个不超过 512 KiB
- 单次最多 10 个附件

通过「＋ → 空间」选择服务器上的文件后，可带回原对话作为附件并保留草稿。小型文本读取内容、图片按图片附件处理；PDF、Word、Excel 等二进制或大文件使用服务器文件路径引用，由 Hermes 在对应档案和工作目录内读取。本机通用二进制文件上传仍不在当前支持范围内。
