# Hermes 3.5.1-preview

日期：2026-09-09。版本号 351，应用 ID `com.qingyu.hermescompanion.preview`。

## 安装

使用与已交付 3.5.0 预览版相同的签名，支持覆盖安装。直接安装 APK，不需要卸载旧版。界面偏好、连接配置与日常对话绑定沿用既有存储。

在「我的 → 设置 → 外观」切换三套皮肤，浅色、深色或跟随系统可独立选择。

## 玻璃实现与验证边界

使用 Backdrop 1.0.6 的页面图层取样。只记录页面内容；导航和弹窗不录入同一个取样层，避免递归绘制。跨窗口菜单、对话框补偿窗口坐标差。

Android 12+ 使用背景模糊；Android 13+ 增加边缘折射。更早系统回退为可读的实体表面，不调用不支持的光学效果。这是 Android 上的自定义实现，不使用 Apple 的系统材质接口。

界面截图来自 Android/Robolectric 原生绘制测试，使用演示资料。静态截图用于检查布局、文字和选中状态；不能据此证明用户手机上硬件合成的折射动效、帧率及耗电表现。本轮没有连接用户的 Hermes 服务器进行实机端到端测试。

## 构建

JDK 21、Gradle 8.13、Android SDK 36 / Build Tools 36.0.0。APP 保持 Java 17 目标字节码，Android 最低版本 26。JVM 测试必须使用 Java 21，因为光学依赖含 Java 21 类文件。

```sh
./gradlew -PhermesPreview=true -PhermesSigningFile=/absolute/path/to/preview.keystore :app:testDebugUnitTest :app:assembleDebug
```

源码不含签名密钥、缓存、构建产物或用户连接信息。重新构建可覆盖已安装预览版的 APK，需要原预览签名。
