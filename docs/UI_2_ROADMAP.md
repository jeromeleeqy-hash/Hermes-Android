# Hermes Android UI 2.0 分批开发计划

## 目标

以“简洁、高效、清爽、明快”为主线，统一清爽办公与液态玻璃两套皮肤。界面先让内容建立层级，再用颜色、形状和动效表达状态，避免依靠大色块和多层卡片制造视觉重量。

## 第一批：设计系统与全局框架（v1.7.0，已完成）

- 重建字体、字号、行高、间距、圆角、透明度、阴影和选中态令牌。
- 清爽办公减少色块、图标底板、胶囊与阴影；液态玻璃建立透光表面、细描边和受控光晕基线。
- 统一底部导航、分段控件、下拉菜单和全局运行状态条。
- 优化首页筛选、会话行、项目标题和“我的”设置列表密度。
- 保证浅色、深色和跟随系统下的文字对比度。

## 第二批：首页与聊天核心体验（v2.0.0，已完成）

- 重构首页头部、筛选展开逻辑、列表空态、加载态和批量操作反馈。
- 聊天页改为内容优先的文档流：统一用户气泡、助手正文、系统消息、工具状态和结果卡。
- 精简输入器色块，重新组织附件、单次语音、命令与会审入口。
- 完成长会话骨架屏、流式状态、定位反馈和键盘/手势过渡。

## 第三批：空间与任务工作台（v2.0.0，已完成）

- 最近产物与项目文件共享统一文件行、类型标识、来源和多选操作。
- 任务统计改为轻量状态摘要，统一待处理、进行中、定时和执行记录卡片。
- 优化详情层级、危险操作、空态、错误态和执行反馈。

## 第四批：我的、设置与全部弹层（v2.0.0，已完成）

- 设置页按“账号与连接 / Agent 能力 / 应用偏好 / 数据与关于”重新分组。
- 统一选择器、确认弹窗、底部表单、错误提示和帮助说明的字号与间距。
- 减少设置项重复描述，补齐搜索、重置、未保存提醒和无障碍语义。

## 第五批：液态玻璃与质量收口（v2.0.0 完成视觉基线，动效与无障碍持续迭代）

- 在支持的 Android 版本评估真实背景模糊，低端设备与省电模式自动降级为预混合透明表面。
- 建立 120–240 ms 的页面、菜单、选中态与状态转换动效，并支持“减少动态效果”。
- 完成大字体、横屏、深色、高对比度、TalkBack、性能与截图回归。
- 统一最终视觉资产、品牌规范和发布截图。

## 验收原则

- 一屏只允许一个最强视觉重点；普通信息不使用高饱和大色块。
- 长列表和正文默认平铺；只有需要表达分组、悬浮或模态层级时使用卡片。
- 可见字号可以更轻更小，但有效触控区域保持 44–48 dp。
- 液态玻璃必须可降级、可读、可维护，不能用模糊效果掩盖信息结构问题。
