Hermes 3.7.4 试用说明

1. 安装 Hermes-Android-3.7.4-release.apk。
   本包沿用 3.7.3 的应用 ID 和签名，可覆盖同包名、同签名旧版。
   如系统提示签名不一致，先保留原 App 和数据，记录提示，不要为安装而卸载。

2. 先体验卡片。
   在“今日”页面点“卡片体验 · 20种”。可以选择、勾选、排序、填写。
   这些是明确标记的示例，只在本地演示，不会发送或写入真实记录。

3. 升级自己的已有卡片。
   连接自己的 Hermes，等首页同步完。
   点“升级交互卡片 · 不查历史”，查看新对话中的请求和附件，点击发送。
   Hermes 应仅转换现有 hermes-today.json：选择合适卡型，长文放背景，保持事实、来源、日期。
   完成后返回首页同步。无需人工把 JSON 复制到手机。
   没有概览时先点“开始整理”，发送附带规范的请求。

4. 配置早晚自动整理（需要时再做）。
   “今日 → 早晚整理”，输入时间和时区（国内通常为 Asia/Shanghai）。
   点“交给 Hermes 配置”会直接打开处理对话并发送请求。
   Hermes 应保存持久规范和脚本，核对现有任务避免重复，报告任务 ID 与下次运行时间。
   对话没有核验成功就不代表已启用；有失败请保留错误信息。
   不需要额外手工安装一个新的服务器软件或数据库。

5. 使用真实卡片。
   打开卡片，选择或填写，再点击底部主按钮。
   App 核对最新版本后打开 Hermes 处理对话；仅点选不代表已更新。
   由 Hermes 核对原记录、保存并回读后确认结果，再同步回首页。
   卡片已改变时先刷新后重新选择；网络失败可在原处理对话重试。
   人物跟进只生成草稿，执行状态卡只核对进度。

同步说明
服务器 JSON 是正式版本；手机保存加密副本。App 前台、恢复前台及对话完成时同步。
完全关闭或离线时不会实时收到每次 Cron 的中间版本，下次打开连接后会读取最新文件。
手机缓存不是 Markdown、附件或服务器的完整备份。

配套 agent-kit
contract.md：与 App 相同的指令约定。
writer.py：Python 3.9+ 标准库校验与原子写入脚本。
examples.json：虚构格式示例，不能当成真实概览导入。
这是排查或手工部署用的配套材料；正常试用由 App 自动携带附件。

本次没有在你的真实手机或服务器上执行安装、文件迁移或 Cron 配置。
