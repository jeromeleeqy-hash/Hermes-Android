# Hermes Android 3.7.5 · 首页与同步修复

本版集中处理首页内容拥挤、卡片与背景区分不清，以及反复进入首页带来的重复读取。沿用原来的服务器 JSON、Markdown、手机加密缓存与 20 种交互卡片，不需要重新配置 Hermes 或升级服务端。

## 首页

- 保留日期、问候、跟我说、帮我做和事项卡片。
- 移除顶部“今日关注 / 资料与记忆”切换、底部资料入口和“接着上次的事”。文件继续通过已有“文件”页访问，目录布局不变。
- 首页中间只显示“值得关注”、事项数量和内容更新时间。长概览、覆盖范围及同步细节移到“概览详情”。
- 右上角菜单集中提供同步、让 Hermes 整理、概览详情、早晚整理、升级卡片和卡片体验。
- 卡片使用 20dp 圆角、不透明主题底色、细边框与轻微阴影；只在显示标题时移除重复的事项类型前缀，不修改 JSON 或事实。

## 同步

- 删除首页组件每次进入时的强制刷新。只有首页处于前台时才约每 60 秒检查一次，并使用同一冷却时间；切回首页不会绕过间隔。
- 已有卡片时后台检查不显示加载条，不禁用操作；首次无内容和用户主动刷新才显示加载状态。
- 合并并发触发。手动刷新、当前 Profile 对话完成均强制读取；若已有请求，最多排队一次补同步，避免遗漏刚写回的结果。
- 每次核对当前配置的工作区。有效的文件修改时间、大小都未变时暂不下载 JSON；最多 5 分钟重新全文校验。手动刷新、操作提交、元数据缺失或变化时均全文读取。
- 失败保留同一工作区的已保存内容，自动重试从 1 分钟逐步退避到最多 5 分钟。不同服务器、账号、Profile 或工作区的内容不混用。
- 不增加后台服务、推送或模型调用。关闭 App 时不会实时同步；下次进入首页检查最新内容。缓存不替代服务器备份。

## 连接

- WebSocket 建立后继续等待 `gateway.ready`，所有并发 RPC 都遵守该条件。
- 握手等待与连接状态锁分离；旧连接回调不能修改替代连接，关闭连接也会使尚未完成的票据请求失效。
- 连接检查复用健康连接，避免无活动对话时仍误关正在进行的其他 RPC。
- RPC 的等待记录在成功、失败与超时后清理。连接失败不自动重放请求，避免重复提交。

这些修复针对已确认的客户端问题。未连接用户真实手机、运营商网络或服务器，不能据此确认所有不稳定因素已消除。

## 安装

使用 `Hermes-Android-3.7.5-release.apk` 覆盖同包名、同签名旧版；包名保持 `com.qingyu.hermescompanion.preview`，版本号 375。无需卸载、重建 Cron 或重新让 Hermes 整理已有卡片。3.7.4 的 Agent 合约保持兼容，不重新要求转换数据。

构建、自动测试、界面检查及签名校验结果见 `VALIDATION-3.7.5.md`。
