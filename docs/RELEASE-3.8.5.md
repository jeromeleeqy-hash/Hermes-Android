# Hermes Android 3.8.5

2026-10-05，基于完整 3.8.4 源码。沿用原包名与签名，可覆盖安装。

## 授权核对与旧提醒

- 原来核对结果显示在根页面提示条，授权 Dialog 会遮住它。现在进度和结果直接显示在授权窗口内；核对期间防止重复点击和提交。
- 官方网关 `_live_session_payload` 会省略空的 `open_requests`；冷启动恢复也可能不返回该字段。原实现因此一直保留旧提醒。现在恢复会话后，如缺少明确列表，读取 `session.events.since` 的显式请求列表，只处理当前请求快照，不重放历史事件，不提交新任务。
- 明确空列表、已过期请求和确实不存在的会话会移除手机残留；网络错误、权限失败、协议缺失、格式错误仍保留待确认状态。使用恢复后的 runtime ID 与原 Profile 查询。
- 无法核对时提供“已处理，移除此提醒”，需要用户再次确认。此操作只修改手机保存的提醒，不发送授权、拒绝、取消或重跑请求。服务器明确仍在等待的请求不提供此入口。
- 授权内容变更和提交失败也显示在窗口内。

实现依据（2026-10-05 核对）：[官方 server.py](https://github.com/NousResearch/hermes-agent/blob/main/tui_gateway/server.py)、[官方 methods_session.py](https://github.com/NousResearch/hermes-agent/blob/main/tui_gateway/methods_session.py)、[官方 server_requests.py](https://github.com/NousResearch/hermes-agent/blob/main/tui_gateway/server_requests.py)。测试复现字段省略和显式空列表两种形态，不将旧网关缺失能力当成成功。

## 页面与设置

- 首页右上角由省略号改为齿轮，直接进入首页设置。
- 设置内按首次整理、可选早晚整理、旧版文件收纳说明配置方式。基础聊天、文件、任务不依赖首页配置；新用户无需执行文件收纳。
- 早晚整理集中于首页设置，打开时只读核对已有配置，带回保存的时间和时区。读取结果不会覆盖用户已经开始修改的输入；保存仍需明确点击。已配置任务无需反复设置，暂停或恢复在任务页操作。
- 维护工具默认折叠，保留只读同步详情与更新整理规则。
- 内容文字操作使用统一的 48dp 点击区域，图标沿正文左边排列。覆盖首页、卡片详情、交互卡片、连接、任务和软件更新入口；对话框确认/取消和导航控件保留各自布局。

## 临时任务与兼容

本版延续手机端分类：自动任务放在“任务”，主动聊天保留在会话列表。服务器记录不删除，PC 仍可能显示它们。跨客户端隐藏需要 PC 或服务器提供相应分类能力，不能仅由安卓端筛选改变。

首页写入协议保持 3.8.4，无需为了本次 UI 修复重配提示词、命令或早晚任务。文件仍放在 `.hermes-app/today/`；已有收纳、刷新回执与未完成操作恢复行为保留。
