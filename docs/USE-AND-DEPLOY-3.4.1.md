# Hermes 3.4.1-preview 使用说明

这次是一次做减法的小更新，基于 3.4.0 保留稳定基础功能，恢复以 Hermes 对话为中心的使用方式。

## 安装

直接安装 Hermes-3.4.1-preview.apk，覆盖原来的 Hermes 预览版。包名和签名沿用之前版本，版本码由 340 升为 341。请勿先卸载；尚未上传的录音和草稿仍然只在本机。

服务器继续沿用现有的 Hermes 远程网关，不需要安装 companion 服务，不需要创建专用 workspace 或手工部署助理文件。

## 怎么用

- 首页点击“跟我说”，进入固定的“日常助理”对话。以后再次点击会查找并继续已有对话。
- 问问题、讨论计划、要求记住某事或创建提醒，都直接在对话中表达；由 Hermes 已有工具处理。缺少工具、权限或信息时，由 Hermes 如实说明或追问。
- 分享文字、网页和附件时，默认发到日常助理。可以补充一句想法，也可通过“换个对话”改发到原项目对话或新对话。
- 日常对话使用 Hermes 默认模型，已有对话保留原模型；仍可在聊天原有模型选择器中修改当前会话。没有自动选择低价模型，没有额外的快问/深入切换栏。
- “回看”找对话，“任务”查看原生定时事项及执行情况，“文件”查看服务器文件与已有成果。
- 新话题仍可在回看页新建，或从首页头像菜单新建。日常入口不会跟随当前选中的项目自动改目录；普通新对话仍继承所选项目。
- 单次录音转写后进入输入框，检查后发送。失败保留原录音，在聊天中可重新识别或删除。

## 哪些流程移除了

移除 3.4.0 的“收下 / 跟进”、工作近况、安排今天、计划草案采用、资料分类编辑以及相处方式独立页面；不再自动启动旧助理资料扫描、上传和上下文拼装。没有新增跨项目自动分流、文件同步系统或手机定时任务执行引擎。

日常消息附加简短的交流与工具使用指导，沿用 Agent 的原身份与记忆，不修改 SOUL、全局模型或服务器配置。手机历史界面显示用户原话，服务器历史仍可能包含这段附加指导。

## 对话恢复与迁移的实际边界

入口绑定只缓存普通 Hermes 会话编号，按服务器、账号和 Profile 隔离，不随项目变化。

无本机绑定时，APP 按服务器最近顺序逐页查找名为“日常助理”的未归档普通对话；有绑定则先读取原会话。只有明确不存在且成功检查历史后才新建，网络错误不会直接创建替代会话。

请保留服务器上的“日常助理”名称，便于重装后发现。手机内的 AI 重命名会跳过此对话。如果电脑端改名，本机仍可按绑定继续并恢复固定名称，但清除本机数据后无法仅凭旧名称找回已改名的对话，可以先在电脑端把它改回“日常助理”。多条同名对话时优先绑定原会话，否则选服务器返回的最近一条；不会合并或删除其他记录。

部分网关直到发送第一条消息后才持久保存空会话。首轮结束后 APP 会补写固定名称；还没发送过消息的空入口不保证能跨设备恢复。两个设备首次同时创建时也可能产生同名会话，本版没有为此引入服务器锁或新数据库。

重装后能恢复服务器已经保存的会话和文件。尚未上传的录音、草稿、本地头像与其他本机配置不能仅靠重新登录自动恢复。

## 旧版资料与提醒

更新不删除 3.4.0 已有的服务器资料、本机旧记录或原生 Cron；旧资料不再作为新聊天的自动依据，也不会自动转换为 Hermes 记忆。原生任务继续在“任务”页管理。

已存在的 3.4.0 本机提醒镜像保留；成功刷新原生定时任务列表后，会移除对应已删除或停用任务的本机镜像。新日常对话不会创建额外的本机镜像。

## 验收时建议先试这几件事

1. 连续打开两次“跟我说”，确认仍是同一条对话。
2. 问一个简单问题，再说“记住我更喜欢简短回答”，观察 Hermes 实际回复与工具结果。
3. 分享一个链接，补一句用途，确认进入原来的日常对话。
4. 到回看页换一个项目，再回首页打开日常助理，确认不会另起项目对话。
5. 对明确的提醒请求，核对 Hermes 的工具结果和任务页，不能仅凭聊天中的口头承诺判断成功。

本地构建与模拟测试不能替代你的服务器和真机联调。语音服务可用性、网关会话接口版本、模型行为和手机后台通知仍取决于实际部署。
