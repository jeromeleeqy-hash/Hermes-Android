## 本次关键验证

- 固定入口复用原会话，不随项目选择创建新对话；重复点击被拦截。
- 本机绑定按服务器、账号和 Profile 隔离，重新实例化存储后仍可读取。
- 本机绑定缺失时从服务器历史查找；覆盖超过第一页的会话。
- 读取失败、不完整结果、分页重复不会被误判为没有会话。
- 新会话使用服务器默认工作目录；名称写入失败前先保留已创建会话编号。
- 所有新增会话读取、查找与重命名请求使用明确的 Profile。
- 晚到的首页查找结果不会抢走用户已经切换到的页面。
- 分享默认进入日常会话，原话和附件继续通过原聊天发送流程处理。
- 320dp 首页、1.3 倍字号深色首页、分享弹窗已通过 Compose 测试并查看渲染截图。
- 既有会话、流式回复、并发、附件、语音、原生任务和布局回归继续执行。

3.4.0 的 AssistantController 和操作 UI 已从生产源码移除。旧资料格式、恢复工具及相关回归代码保留用于历史兼容；它们不再由主界面初始化或自动同步。

## 实际环境限制

没有连接用户真实服务器，也没有在用户真实手机上安装。测试中的网关、会话、工具响应来自模拟环境；这些测试不能证明真实 Agent 一定会成功记忆、创建提醒、转写语音或推送通知。

本次没有部署服务器服务、创建用户服务器文件、修改用户 SOUL/全局模型或迁移服务器资料。

覆盖升级的判断来自包名、版本码和证书比对；安装及语音、通知效果仍需真机验证。首次空会话的持久化和固定名称写回取决于现有网关，详见使用说明。
