Hermes Android 3.8.0 使用说明

1. 安装
安装 Hermes-Android-3.8.0-release.apk，覆盖原版本，不要先卸载。交付包沿用原预览版包名与签名，版本为 3.8.0 / 380。已有连接、外观、缓存和对话配置继续保留。

2. 让现有首页采用新规则
打开首页右上角“…” → “调整首页整理方式”。App 会把新版规范发给 Hermes，调整当前概览和能核实匹配的已有早晚整理任务。需要服务器审批时，正常查看具体内容并答复。
处理结束后返回首页刷新。已有早晚任务无需重建；这次调整保留原时间、时区、任务 ID 和启用状态。若 Hermes 没有找到对应任务，应说明跳过的部分，不能把“已发送提示词”当成配置成功。
尚未配置过概览的用户，才使用同一菜单内的“早晚整理”设置时间并配置。

3. 新版日常使用
首页先看关注事项、值得收尾的事和提醒。卡片以清楚的背景、现状、真实进展与数据为主；点击“聊聊这件事”带着背景继续对话。
你可以自然说明“这件事已经完成”“先放到下周”“这已经不是我的重点”“我现在主要在做……”；Hermes 按现有工作区规范处理。只有明确写入并验证成功，才算已记录。
详情里的背景与来源默认收起；旧卡的快捷回应仍可使用，没有强制每件事都做选择题。
对话页“参考资料 · N”默认只占一行，需要时展开；“处理详情”也默认收起。原始消息和真实失败不会被删除。
文件页直接查看工作区，不再显示“最近产物”。任务页只分当前、定时、记录；定时卡右侧“…”保留查看详情、运行一次和删除安排。

4. 保留与限制
继续使用服务器上的 Hermes、JSON 和 Markdown，不需要新增数据库。手机仍在可连接时同步概览副本。
安装 APK 不会自动修改服务器文件或 Cron；第 2 步需要由你的 Hermes 实际执行。旧数据可以显示，但旧提示词生成的长文不会凭空变成更懂你的内容。
本次保留已有审批和重连能力，但未连接你的真实服务器，不能保证此前的网络问题已解决。若仍出现，请保留“我的”中连接诊断的具体错误和时间，便于区分手机连接、网关和任务处理问题。

5. 中断操作
旧卡“继续未完成部分”仍可使用。它应核对原结果，只补未完成的同步，不覆盖后续更新。新的决定使用新的操作编号，不借用旧操作结账。
