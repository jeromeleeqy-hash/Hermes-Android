# Hermes Telegram 图标系统

## 设计原则

- 图标母版统一使用 256 × 256 精细网格，转换为 Android VectorDrawable 后按 24 dp 固有尺寸参与布局。
- 底栏固定 22 dp，设置和主要列表为 19–20 dp，紧凑操作为 17–18 dp，微型状态为 12–16 dp；触控区域独立保持 40–48 dp。
- 使用圆润几何、适度留白和一致的光学重量，轮廓以闭合填充路径构造，避免线条断点、端点叠加和交叉毛刺。
- 导航图标同时提供线性与实体形态；未选中显示线性图标，选中后以淡入、缩放和主题色过渡到实体图标。
- 页面操作图标使用单色矢量并由 Compose 按主题着色；设置入口使用白色图形配语义色圆角底板。
- 造型优先采用圆角矩形、圆弧与简化几何面，控制各图标的光学占比和重心。
- 图标造型服务于统一的 Telegram 式清爽办公界面，不再为皮肤切换增加不同容器。
- 选中状态由滑动浅色底板、实体图标、文字颜色与字重共同表达，动画与页面切换同步。
- 返回、关闭、发送、展开等平台操作同样使用精细图标资源，避免页面风格断裂。
- 删除无功能含义的独立圆点、随机色块和装饰角标；通知铃舌、图片太阳等语义细节不受此限制。

## 语义色

| 颜色 | 浅色模式 | 主要语义 |
| --- | --- | --- |
| 蓝 | 主题 `primary` | 主要操作、选中状态、来源跳转 |
| 青 | `#16A7B8` | 语音、同步、模型和网页 |
| 绿 | `#20B889` | 连接、完成、运行和 Markdown |
| 琥珀 | `#E39A27` | 文件夹、置顶、等待和提醒 |
| 红 | 主题 `error` | 删除、错误和停止 |
| 紫 | `#7666E8` | AI、Soul、技能和产物 |
| 中性 | 主题 `onSurfaceVariant` | 返回、关闭、列表和低优先级操作 |

显式按钮可覆盖语义色，例如设置页彩色底板上的图标统一使用白色。其余图标自动跟随 Material 浅色与深色主题。

## 工程结构

- 设计母版：`design/*-icons-refined/icons/**/*.svg`
- Android 生成资源：`app/src/main/res/drawable/hermes_refined_*.xml`
- 品牌标志：`app/src/main/res/drawable/hermes_logo_mark.xml`
- Compose 统一入口：`ui/component/HermesIcons.kt`
- 生成脚本：`tools/import_refined_icons.py`

业务页面只能通过 `HermesIconKind` 和 `HermesMulticolorIcon` 调用语义图标，不在页面中重新绘制同类图标。

八轮图标已经全部进入统一资源库；当前业务页面不再直接引用旧图标资源。新增页面应优先复用现有 `HermesIconKind`，确有新语义时再从母版补充并重新运行导入脚本。
