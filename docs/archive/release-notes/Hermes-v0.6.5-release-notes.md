# Hermes Android v0.6.5

本版本补齐对话离开页面后的持续回复与未读提醒，并统一聊天身份资料和底栏图标状态。

## 主要更新

- AI 回复未完成时返回会话列表，请求会继续运行，不再因页面切换而停止。
- 回复完成后按通知设置发送系统消息；未打开查看的对应会话显示红色未读点，打开后自动清除。
- 个人资料支持分别设置用户与 Hermes 的头像、昵称；Hermes 资料仅显示在聊天界面。
- “我的”顶部用户头像容器改为圆角矩形。
- 底栏当前页面图标保持彩色，其余图标以保留明暗层次的灰度显示。
- 调整“我的”图标头身比例，简化定时任务时钟图标。

## 构建信息

- 版本：`0.6.5-debug`（versionCode 30）
- 最低系统：Android 8.0（API 26）
- 目标系统：Android API 36
- 17 项单元测试全部通过
