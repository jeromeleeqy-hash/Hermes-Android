# Hermes Android 3.8.2

日期：2026-10-04。版本号 382，沿用原包名与签名，可覆盖安装 3.8.1。

## 界面

- 首页音波图标跟随按钮文字颜色，适配蓝色、绿色和深浅色主题。
- 小尺寸人物改用已有半身动图，点击动作按半身裁切；减少动态效果设置继续有效。
- “帮我做”使用与详情页一致的固定阅读窗口，提供会议、资料、方案、研究、写作、生活六个入口。场景可取消选择，也可直接输入。只有点“开始聊聊”才进入对话，不会选择后自动执行。
- 助理、回看、任务、文件、我的统一使用 20dp 左右边距。文件页双列网格作为一个整体与其他页面对齐，大字号继续单列。

## 软件更新

“我的 → 设置 → 软件更新”和“关于 Hermes → 检查软件更新”均可打开。

- 从 `https://download.leaier.com/releases/android-latest.json` 检查版本，与 Hermes 网关连接、登录、workspace 无关。
- 自动检查默认开启，每天打开 App 时最多检查一次，可关闭；不会自动下载、自动安装或弹窗打断聊天。
- 有新版时在设置中提示，展示更新内容与大小，用户点击后才下载。默认仅 Wi-Fi，关闭后可使用移动流量；不使用漫游。
- Android 系统下载管理器负责下载，关闭更新窗口、切换页面后仍可继续。App 重启会恢复已保存的下载记录并重新核验。
- 安装前验证字节数、SHA-256、包名、版本及签名身份。篡改、不兼容、同版本或降级包无法安装；公开更新源不会获取 Hermes 登录凭据。
- 下载的文件仅存放于 App 专用目录，向系统安装器临时开放单个文件。首次安装需要允许此 App 安装应用，系统最终确认安装，不支持静默安装。
- HTTP 403、404、更新源异常、存储不足和校验失败各自说明；不会混报为 Hermes 服务器连接异常。

旧版尚无更新入口，第一次需要手动安装 3.8.2；之后才能在 App 内下载后续新版。已经安装 3.8.2 时，版本信息也是 3.8.2 会显示“已是最新版本”，这是正常行为。
