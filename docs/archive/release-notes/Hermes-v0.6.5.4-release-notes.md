# Hermes Android v0.6.5.4

本版本修复 Android 16 上的相册头像授权闪退，并扩大应用图标安全区。

## 修复内容

- 头像 URI 读取出现权限异常或图片损坏时安全回退，不再从主线程抛出异常导致闪退。
- 新选择的用户头像与 Hermes 头像复制到应用私有目录，不再依赖系统相册的临时读取授权。
- Hermes 自定义头像无法读取时回退为内置 Hermes 图标。
- 桌面自适应图标进一步缩小人物构图，减少 OnePlus 等厂商桌面对头发、耳机和肩部的裁切。

## 升级提示

如果旧版本保存的头像已经失去系统相册授权，升级后应用会正常打开并显示默认图标。进入“我的 → 顶部头像 → 个人资料”重新选择一次头像，即可迁移到新的私有存储方式。

## 构建信息

- 版本：`0.6.5.4-debug`（versionCode 34）
- 最低系统：Android 8.0（API 26）
- 目标系统：Android API 36
