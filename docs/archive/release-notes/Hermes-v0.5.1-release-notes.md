# Hermes Android v0.5.1

## 本次修复

- WebSocket 增加 20 秒心跳保活，减少手机网络抖动或网关回收空闲连接造成的随机断线。
- 流式回复中断后自动重新连接 Hermes 远程网关。
- 重连期间不会重复提交用户消息，避免生成两份相同回答。
- 自动查询当前会话的最新消息；服务器继续生成完成后，回答会同步回聊天页面。
- 聊天标题栏在恢复期间显示“正在重连”。
- 不再把 `Software caused connection abort` 等系统英文异常直接展示给用户。
- 断线、失败或手动停止后，自动移除没有内容的助手占位气泡；已经接收的部分回答会保留。
- 长会话恢复时会先读取服务器最新消息数量，确保最后 200 条中包含刚生成的回答。

## 安装说明

- 包名：`com.qingyu.hermescompanion.debug`
- 版本：`0.5.1-debug`（versionCode 15）
- 使用与 v0.3.1–v0.5.0 相同的固定签名，可直接覆盖安装。
- Android 8.0 及以上系统可安装。

## 建议验证

1. 覆盖安装后正常进入已有聊天。
2. 连续发送 3–5 条消息，确认回复能够持续生成。
3. 生成过程中短暂关闭再打开 Wi-Fi，标题栏应显示“正在重连”。
4. 网络恢复后等待片刻，服务器已完成的回复应自动同步，且不会出现重复用户消息或空白回复气泡。
