# Hermes 3.6.2 正式版

这次采用确认的新图标与头像，增强玻璃控件可读性，并补齐历史更新日志。

## 本次更新

1. 软件图标采用选定的白发耳机女孩方案，覆盖桌面自适应图标和应用品牌入口。
2. Hermes 默认头像使用选定的人像图，回复、个人资料中的助理预览等共用该默认资源。
3. 默认用户头像换为通用卡通人物；用户自己上传的两类头像继续优先显示。
4. 玻璃输入框增加独立底色、可辨边线和焦点状态；主按钮使用克制的蓝色渐变，次按钮使用浅色底与描边。同步覆盖详细设置、语音自定义值、工作目录、定时任务及提示词编辑，并调整深色禁用态。
5. 模型提供商的多字段表单改为统一底部面板，修复旧对话框的持续布局问题；保留输入内容，表单可滚动，底部操作固定。
6. 中英文更新日志补齐为 **63 条可核对版本记录**，修正 3.0.3 与 3.0.3a 内容错配；当前版本展开，旧版本点按查看。

## 前面约定的优化一起保留并回归

- 三套独立首页、首页和对话人物视觉居中、普通字号玻璃首页两条近期事项。
- 回看圆角分组、统一菜单圆角、所有主页面底栏下方遮挡，底栏内部继续保留透光。
- 三套皮肤的详细设置控件、弹层底部安全区、自定义提示词，以及简洁的对话菜单。
- Windows 盘符和 UNC 共享目录、Linux 绝对目录，中英文与跟随系统切换。
- 现有角色动画、单次和连续语音、日常会话绑定及自定义头像不重置。

## 安装

下载 **Hermes-3.6.2.apk** 后直接覆盖当前同签名预览版，无需先卸载。桌面名称为 **Hermes**，版本显示 **3.6.2**；这是关闭调试的 Release 构建。

为保留现有应用数据，安装身份沿用 `com.qingyu.hermescompanion.preview` 和原签名，内部版本号提升为 **362**。该内部包名不代表安装包仍为预览版；若改包名会被 Android 当成另一款软件。

最低 Android 8.0。Android 12 及以上使用玻璃取样，较早系统使用可读的兼容表面。

## 对应源码

源码包含选定原图、资源导出脚本、63 条中英文版本数据、对应测试和本版渲染图。源码包不含签名私钥、连接配置、录音或构建缓存。

构建命令（JDK 21、Gradle 8.13、Android SDK / Build Tools 36）：

```sh
./gradlew -PhermesPreview=true -PhermesSigningFile=/absolute/path/to/hermes-preview.keystore :app:testDebugUnitTest :app:assembleRelease
```

输出为 `app/build/outputs/apk/release/app-release.apk`。同签名覆盖升级需要原签名文件。
