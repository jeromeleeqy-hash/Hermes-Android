# Hermes 0.6.5.7

本版本修复 0.6.5.6 中头像已提示选择成功、但预览和保存后仍无变化的问题。

## 原因

图片选择和私有 PNG 转换实际已经成功，页面出现“恢复默认”说明头像路径也已写入草稿。问题发生在显示阶段：应用把私有文件包装成 `file://` URI 后仍交给系统 `ContentResolver` 读取，部分 Android 16 厂商实现无法稳定完成这条读取链路，失败后头像组件回退成了昵称首字母。

## 修复

- 新导入头像直接保存应用私有文件的绝对路径。
- 头像组件识别私有路径和旧 `file://` URI后，直接使用文件流解码，不再经过 `ContentResolver`。
- 写入 PNG 后立即使用标准位图解码器验证尺寸；验证不通过不会再提示成功。
- 继续保留外部 `content://` URI 的安全降级兼容，失效时不会造成闪退。

## 升级

已安装 v0.3.1–v0.6.5.6 的设备可以直接覆盖安装，不需要清除数据。0.6.5.6 已经选过的头像路径仍受兼容；若头像仍是旧状态，在个人资料中重新选择并保存一次即可。
