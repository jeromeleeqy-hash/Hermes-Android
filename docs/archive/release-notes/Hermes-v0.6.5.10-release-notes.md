# Hermes 0.6.5.10

本版本补齐聊天图片的直接预览，并统一从聊天打开文件后的返回行为。

## 聊天图片内联预览

- 支持 `@image:/root/.hermes/images/图片.png` 形式的 Hermes 图片引用。
- 支持 `![说明](/root/.hermes/images/图片.png)` 标准 Markdown 图片语法。
- 图片通过当前远程网关异步读取，加载完成后在消息正文中显示真实缩略图。
- 点击缩略图可进入全屏预览，并支持原有的双指缩放与拖动。
- 当前会话会缓存已加载的图片；加载失败仅保留可点击图片卡片，不影响聊天页面。

## 预览返回对话

- 从聊天打开 Markdown 文档后，点击顶部返回箭头会直接返回原对话。
- Android 系统返回键和返回手势执行同样的逻辑。
- 从聊天打开图片采用覆盖式预览，关闭预览后仍停留在当前对话。
- 从空间页打开文档或图片时维持原有层级，不会错误跳转到聊天。

## 升级

已安装 v0.3.1–v0.6.5.9 的设备可以直接覆盖安装，不需要清除数据。
