# Hermes Android 1.5.0

本次升级聚焦长对话性能、移动端命令操作和有实际决策增益的多 Agent 会审。

## 新功能

- 命令面板：输入区新增 `/` 按钮，读取服务器完整命令目录并按当前 Profile 缓存；支持搜索、分类浏览，点选只插入命令，避免误执行。
- 深度专家会审：Hermes 主 Agent 使用 `delegate_task` 并行委派证据、反方和落地专家，只有高影响分歧未解决时才追加至多一轮定向复核。
- 快速专家会审：服务器已配置 MoA 时，可切换到 MoA 预设，由参考模型并行分析、聚合模型完成裁决。
- 会审结果不会展示模型间原始互聊，只保留会审进度、结论、共识、关键分歧与裁决、证据风险、相对单 Agent 的增益和置信度。

## 性能优化

- 普通聊天首次只加载最近 60 条，顶部可继续按 60 条加载更早历史；从搜索进入时仍读取最近 200 条以保证定位范围。
- 流式增量按约 50ms 合帧，生成中使用轻量文本，完成后再渲染完整 Markdown、引用与图片，显著减少长回复刷新频率。
- 最近产物按会话更新时间、消息数和摘要生成指纹，只扫描变化的会话；每个会话扫描最近 80 条，并一次性合并写入缓存。

## 会审边界

- 深度模式没有 `delegate_task` 能力时会明确标注降级，不会用角色扮演伪造多个 Agent。
- 简单问题允许 Hermes 判断为“无需会审”并直接回答，避免为形式化群聊浪费 Token。
- 快速模式依赖服务器已有 MoA 预设；未配置时仍可使用深度会审。

## 安装

版本号 `1.5.0`，`versionCode 150`，最低支持 Android 8.0。安装包沿用工程内固定开发签名，v0.3.1–v1.4.0 可直接覆盖安装。
