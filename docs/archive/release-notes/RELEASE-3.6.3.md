本次按反馈中的四项遗留问题和六项新增要求逐条修改。以下为本版实际实现及验证范围。

## 十项修改

| 反馈 | 本版处理 | 检查依据 |
| --- | --- | --- |

## 安装及首开体验

下载 **Hermes-3.6.3.apk** 直接覆盖同签名 3.6.2，无需先卸载。内部版本号为 **363**，应用名称 **Hermes**，属于不可调试的 Release 构建。

为保留现有数据，包名沿用 `com.qingyu.hermescompanion.preview`，签名与 3.6.2 一致。覆盖安装不会更换用户自定义头像或重置本地昵称。

- 全新安装：开场动画 → 认识彼此（头像、助理昵称、你的称呼、主题与语言）→ 连接网关。
- 已有安装：本次新增开场展示一次，已有身份和连接流程保留，不要求重做身份设置。
- 重看动画：**我的 → 使用说明**，目录底部点击“重看开场动画”。启用“减少动态效果”时显示首帧后继续。
- 修改昵称和头像：**我的 → 编辑信息**。网关账号只用于服务器登录，不随本机昵称改变。
- 本地视频约 **1.93 MiB**，默认静音。手动锁屏仍按系统行为执行。

## 对应源码与使用指引

源码包包含本版 UI、视频与首帧、资源导出脚本、中英文分级操作指南、64 条历史版本数据、测试和本版渲染图。不含签名私钥、连接凭据、录音或构建缓存。

常用文件：`docs/OPERATION-GUIDE.md`、`docs/OPERATION-GUIDE.en.md`、`docs/VALIDATION-3.6.3.json`、`docs/UI-3.6.3.png`。

构建环境：JDK 21、Gradle 8.13、Android SDK / Build Tools 36。使用原签名文件构建才能继续覆盖现有安装：

```sh
./gradlew -PhermesPreview=true -PhermesSigningFile=/absolute/path/to/hermes-preview.keystore :app:testDebugUnitTest :app:assembleRelease
```

视频资源可使用 `python3 tools/prepare_intro.py /path/to/approved-intro.mp4` 重新导出。片头首帧放在 `drawable-nodpi`，避免高密度设备解码出不必要的大位图。
