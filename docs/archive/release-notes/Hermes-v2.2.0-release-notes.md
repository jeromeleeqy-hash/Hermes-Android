# Hermes Android 2.2.0

发布日期：2026-08-16

本次升级延续 Telegram 式清爽办公方向，重点解决下拉菜单过大、按压态出框、入口图标错误，以及首页、聊天和设置页仍偏松散的问题。

## 界面与交互

- 首页移除重复的小标题，压缩头部、筛选栏和会话行；右下角新对话按钮改用清晰的铅笔图标。
- 下拉菜单改为紧凑行高与小字号，选中标记独立对齐；筛选器和列表按压反馈保持圆角。
- 搜索页改为单行“返回 + 搜索框”工具栏，打开后直接输入。
- 聊天输入器降低高度，普通工具入口取消重复色块；连续助手消息不再重复头像和名称。
- 最近产物以小图标进入来源会话，减少重复文字；文件、任务、我的和设置页同步提升信息密度。
- 执行中心修复新建图标并简化页头、摘要与定时任务卡。
- 微调全局字号和行高，同时保留低饱和多色语义层次。

## 兼容性

- 保留现有网关、聊天、语音、空间、任务、通知及全部服务端设置能力。
- 使用与 v0.3.1 以后版本一致的固定开发签名，可直接覆盖安装。
