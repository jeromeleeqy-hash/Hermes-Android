# Hermes Android v0.6.1

## 本次升级

- 深色模式重新拉开背景、区块、分割线、文字与图标层级，并让系统栏图标随 APP 主题正确反色。
- 原“轻透毛玻璃”改为不透明的“圆润卡片”风格，保留圆角和轻阴影，移除透明叠层及聊天顶栏的白色反光矩形。
- 会话切换控件缩小；任务页统计改为数字居中；空间、任务和“我的”移除重复顶部标题，内容整体上移。
- 设置页与任务详情顶栏固定，所有设置和任务开关缩小；技能 / 工具集 / MCP 与任务使用同一分段控件。
- 用户聊天消息新增本机头像与昵称，“我的”设置页可直接编辑个人资料。
- Markdown 编辑和预览缩小字号、扩大有效编辑区、修正表格列对齐与横向滚动，并缩小代码复制按钮。

## 安装说明

- 包名：`com.qingyu.hermescompanion.debug`
- 版本：`0.6.1-debug`（versionCode 22）
- 使用与 v0.3.1–v0.6.0 相同的固定开发签名，可以直接覆盖安装。
- Android 8.0 及以上系统可安装。

## 建议验证

1. 在 APP 内切换浅色、深色与跟随系统，确认状态栏、导航栏、正文和多色图标都保持清晰。
2. 切换“清爽办公 / 圆润卡片”，打开菜单、底部弹层和对话页，确认弹层完全不透明且没有白色反光矩形。
3. 滚动模型设置、个人资料、通知设置和定时任务详情，确认标题与返回按钮固定在状态栏下方。
4. 设置头像和昵称后发送消息，确认用户头像、昵称和气泡同时显示。
5. 打开包含宽表格与代码块的 Markdown 文档，在预览和编辑状态下确认列对齐、横向滚动、复制按钮与底部留白。
