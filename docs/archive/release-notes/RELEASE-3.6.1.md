# Hermes 3.6.1-preview

本次版本细化三套界面的组件，并加入 Windows 工作目录与中英文界面。

## 界面调整

- 玻璃首页按可用屏幕高度安排人物、主按钮和近期事项。普通字号下可完整显示两条近期事项；标题、摘要各保留一行，点按打开完整会话。小屏、大字号或出现待确认事项时仍可滚动。
- 首页与对话页共用稳定的人物裁切中心，校正素材本身的右偏，不逐帧移动裁切框。
- 回看页时间分组改为圆角容器；圆角按内容卡片、按钮/输入框、下拉菜单、弹层、导航栏分别规范。
- 助理、回看、任务、文件、设置共用底部遮罩：导航栏下方与系统手势区域使用不透明页面底色，导航栏内部保留透光效果。
- 玻璃按钮、开关、单选项与设置输入框加入克制的高光和边缘层次；温暖、安静两套界面的详细设置组件同步使用各自规范。
- 首页定时会话摘要显示可读的执行入口提示。

## Windows 工作目录

支持 `C:\Users\Name\workspace`、`D:/Hermes/My project`、`\\server\share\workspace`，并继续支持 Linux 绝对路径。

新建项目可直接输入绝对路径或浏览目录。路径比较支持 Windows 盘符大小写和两种分隔符，保留驱动器根目录语义；相对路径 `C:workspace` 不作为绝对路径接受。目录存在与访问权限由所连接的服务器决定。

## 语言

入口：**我的 → 设置 → 语言**；未连接时也可点击 **简体中文 / English**。

支持跟随系统、简体中文、English，覆盖导航、设置、弹窗、状态、应用提示、日期和默认提示词。已有会话、用户提示词、文件名和服务器返回内容保留原文。界面语言不会改变 Agent 的模型或语音偏好。

英语用户可直接参考源码中的 `docs/QUICK-START-EN.md` 或单独提供的英文快速指南。

## 安装与验证

- 版本：3.6.1-preview，内部版本号 361；Android 8.0 及以上。
- 沿用 3.6.0-preview 的应用标识与签名，可覆盖更新该预览版并保留应用数据。
- 276 项自动化检查全部通过，覆盖三套风格、深浅色、中英文、小屏大字号、底部区域、语言切换保留草稿和 Windows 项目输入。
- APK 签名、ZIP 完整性、16 KB 对齐及单 DEX 结构校验通过。
- 界面图来自原生 UI 测试渲染；本次未连接实体手机或实际 Windows Hermes 服务器，实机玻璃动态表现及服务器目录权限仍需在对应设备上确认。
- Android 12 及以上使用背景模糊与浅透镜效果；Android 8–11 使用清晰可读的兼容材质。
