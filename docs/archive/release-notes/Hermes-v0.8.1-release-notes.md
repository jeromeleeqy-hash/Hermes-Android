# Hermes Android v0.8.1

本版本针对 v0.8 真机反馈修正四处交互问题。

## 修正内容

- “跳到底部”缩小为圆形向下箭头，并确保定位到最后一条长消息的末尾。
- “最近 / 项目”合并进筛选栏，减少首页纵向占用。
- 头像裁剪的左右、上下滑块现在会实时移动预览，并与最终裁剪结果保持一致。
- 修复 Profile 菜单错误显示 `false`：布尔值不会再被当作 Profile 说明文字。

## 构建信息

- 版本：`0.8.1-debug`
- versionCode：`81`
- applicationId：`com.qingyu.hermescompanion.debug`
- 最低系统：Android 8.0（API 26）
