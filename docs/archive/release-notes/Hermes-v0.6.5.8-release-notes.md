# Hermes 0.6.5.8

本版本按照最终确认方案取消头像上传功能，用户和 Hermes 均改为固定内置头像。

## 用户头像

- 使用用户提供的竹林背景、金框眼镜卡通人物图片。
- 原图等比居中处理为 512 × 512 内置资源，不改变人物和背景构图。
- “我的”主页、个人资料页、用户聊天消息等所有位置统一使用该图片。

## Hermes 头像

- 继续使用当前内置的棕发青色耳机 Hermes 形象。
- 对话列表、聊天消息、聊天助理面板等位置保持一致。

## 设置调整

- 删除用户头像和 Hermes 头像的选择、处理、保存与恢复默认按钮。
- 删除系统照片选择器和私有头像文件存储代码。
- 历史配置中的自定义头像路径不再读取，保存个人资料时自动清空。
- 个人资料页继续支持用户昵称、个人签名和 Hermes 昵称设置。

## 升级

已安装 v0.3.1–v0.6.5.7 的设备可以直接覆盖安装，不需要清除数据。
