# Hermes Android 3.8.4

2026-10-05。基于完整 3.8.3 源码，沿用原包名 `com.qingyu.hermescompanion.preview` 和原签名，versionCode 为 384。

## 本次调整

- 授权使用单一固定窗口，不再使用可拖动的底部弹层。命令、原因和选项内部滚动，确认按钮固定在底部；同一请求不会因首页卡片和全局弹窗同时展示两次。核对状态、重新接入运行会话时保留当前选择，授权内容变化时清空旧选择。
- 首页授权卡片改为一个整行“查看并确认”按钮，移除挤在两列中的长选项。弹窗按钮限制单行；完整选项说明保留。
- 手机回到前台，以及有待确认请求时，每 10 秒按请求所属 Profile 核对服务器状态；另有手动“核对状态”入口。服务器明确返回空请求列表或原会话不存在时，清除本机残留。取消/过期事件脱离当前消息流也可处理。网络失败、无权访问或旧服务器没有明确列表时保留请求。
- 提交授权前核对请求。已在 PC 处理的请求不再提交；命令、问题、选项或允许范围有变化时要求重新查看确认，不套用旧答复。
- 首页菜单只保留“早晚整理”和“首页设置”。设置说明日常刷新、只需一次的文件收纳和按需使用的维护工具；已从新位置读取文件时显示已收纳，不再提供重复迁移按钮。
- App 发起的概览刷新、整理、修复、规则更新、时间配置、文件收纳和卡片操作归入“任务”，从普通会话、对话搜索、分享目标和普通会话批量重命名中排除。主动聊天及“聊聊这件事”仍是普通对话。任务详情可查看处理过程和补充要求；没有自动删除任何会话。

## 兼容与存储

任务标记按服务器、账号、Profile 和会话 ID 隔离并保存在手机。升级时从已保存的卡片操作和 Android 会话的首条请求附件识别旧 App 任务；不根据标题关键词猜测。只读取已列出的 Android 会话开头消息，成功检查后不重复读取。读取失败时保留原显示，后续刷新可重试。

沿用 3.8.3 的刷新回执、卡片动作回执、并发锁和文件迁移：

| 内容 | 收纳后位置 |
| --- | --- |
| 首页概览 | `.hermes-app/today/hermes-today.json` |
| 协作锁 | `.hermes-app/today/.hermes-today.lock` |
| 概览快照 | `.hermes-app/today/snapshots/` |

安装 APK 不会自动搬动服务器文件。旧工作区可在“首页 → ⋯ → 首页设置 → 收纳首页文件”执行一次。该任务会同步规范、writer 命令和可核实匹配的既有概览 Cron；保留任务 ID、时间、时区与原启用状态。源业务文件和其他程序的快照不搬动，冲突时保留资料。

## 验证与边界

构建和回归结果见 [VALIDATION-3.8.4.md](../../VALIDATION-3.8.4.md)。自动化覆盖布局稳定、单行按钮、跨端已处理、过期、未知状态、网络失败、连接切换、授权内容变化、任务归类及既有恢复流程。PC 与手机状态同步使用模拟网关验证；本环境未连接用户的真实 Hermes 网关，也未进行真机或 OSS 验收。
