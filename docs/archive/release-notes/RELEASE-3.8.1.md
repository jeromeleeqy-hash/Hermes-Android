# Hermes Android 3.8.1

这次针对真实手机截图优化 UI/UE，以清楚呈现事情、自然继续聊天为主。保留现有三种皮肤、人物、底部导航及服务器 JSON/Markdown 架构。

- 首页合并日期和问候、缩小人物及按钮占位，让第一张事项更早出现；移除卡片中重复的提醒理由。历史提及日期只在详情显示，真实日程才突出时间。
- 对话阅读页显示最近提问和本轮答复，去掉多层重复标题。明确标注的处理日志默认折叠；涉及失败、审批、冲突等的日志保留可见，完整对话和复制仍保留原文。
- 任务记录使用中性对话图标，不把回复结束当作业务成功；从真实答复抽取摘要，只有开场叙述时提示查看回复。安排按下次运行时间排列，暂停项可展开；常见周计划显示具体星期和时间。
- 文件夹双列展示；大字号自动单列。隐藏文件、首页 JSON 及已知 App 配置默认收起，菜单可显示全部，所有原文件保留。
- 我的页面使用紧凑资料头部，常用功能集中为列表；文件路径留在实际文件页。短事项详情改为固定高度阅读窗口，滚动不改变弹层高度。
- 早晚整理约定进一步强调确认连续性：不以较新生成的总结推翻已确认决定，不把回执缺失当成用户没回答，有冲突明确说明。正文只汇报事情的结果，诊断记入 processing_notes。

安装后界面立即生效。已有卡片的内容和早晚 Cron 不会随安装自动重写；在首页菜单选择“调整首页整理方式”，App 会交给 Hermes 执行，完成后核对结果。此模式只调整核实匹配的已有任务，不创建重复 Cron，不修改原业务记录。

本版本不新增数据库、Agent 或服务器环境。结构校验不能自动证明语义真实；没有连接用户真实服务器，不宣称已修复移动网络或核对完历史记忆。
