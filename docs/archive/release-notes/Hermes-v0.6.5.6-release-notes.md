# Hermes 0.6.5.6

本版本修复用户/Hermes 头像无法上传的问题，统一返回箭头颜色，并让聊天中的 Hermes 文件地址可以直接点击打开。

## 头像上传

- 用户头像和 Hermes 头像统一改用 Android 系统照片选择器。
- 选中图片后立即复制、解码、纠正系统支持的图片方向、限制最长边为 1024 px，并重新编码成 APP 私有 PNG。
- 不再依赖相册 URI 的长期授权，也不依赖原图扩展名；处理中按钮会显示状态，成功和失败均有明确提示。
- 选择完成后仍需点击页面底部“保存”，避免误选图片直接覆盖原资料。

## 返回箭头

- 所有页面的返回箭头改为纯灰色。
- 浅色模式使用中性深灰，深色模式自动使用高对比浅灰。

## 聊天文件链接

- `MEDIA:/root/workspace/文件.md` 会显示为可点击的蓝色下划线链接。
- Markdown 文件在 APP 内打开，可继续预览和编辑；图片进入全屏图片预览。
- 标准 Markdown 链接同样支持点击，HTTP/HTTPS 地址使用系统浏览器打开。
- 当前无法直接预览的远程文件类型会显示明确说明。

## 升级

已安装 v0.3.1–v0.6.5.5 的设备可以直接覆盖安装本版本，不需要清除数据。
