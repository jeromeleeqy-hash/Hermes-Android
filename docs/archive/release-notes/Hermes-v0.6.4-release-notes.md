# Hermes Android v0.6.4

本版本完成 Hermes Light 全量图标与应用启动图标的正式接入。

## 视觉更新

- 全软件 79 枚图标统一为轻量、圆润、克制的 Hermes Light 风格。
- 所有页面与弹层的 Material 默认图标均已替换，状态圆点和底部弹层拖动条也使用正式设计资源。
- 图标提供独立深色模式色板，深色背景上的中性线条与操作图标会自动提亮。
- 发送、停止等彩色图标改用浅色语义容器，减少混色与视觉重量。
- 新的 Hermes 女生应用图标采用全幅自适应构图，重点人物与翅膀位于系统蒙版安全区，避免打包后被切掉。

## 构建信息

- 版本：`0.6.4-debug`（versionCode 25）
- 最低系统：Android 8.0（API 26）
- 目标系统：Android API 36
- 13 项单元测试全部通过
- Debug APK 已通过 v2 签名与 16 KB 页面边界对齐检查
