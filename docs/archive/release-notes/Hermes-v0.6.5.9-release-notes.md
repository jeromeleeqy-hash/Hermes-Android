# Hermes 0.6.5.9

本版本精简对话列表顶部状态信息，重做聊天中的 Markdown 文档跳转，并修复表格行高错乱。

## 对话列表顶部

- Hermes 昵称下方由“个人助理 · 网关在线”改为“网关在线”。
- 保留连接状态图标与现有字号、间距。

## 聊天文档链接

- 支持识别 `MEDIA:/root/workspace/文件.md`。
- 支持识别 `[文件名](MEDIA:/root/workspace/文件.md)` 等标准 Markdown 链接。
- 支持从带说明文字的消息行中提取 `/root/workspace/文件.md` 绝对路径。
- 文档从普通文字链接升级为独立文档卡片，整张卡片均可点击。
- 点击卡片后直接读取 Hermes 远程工作区文档，并跳转 APP 内 Markdown 预览和编辑页面。

## Markdown 表格

- 每行高度统一取该行内容最高的单元格，所有列的背景和边框完整铺满整行。
- 修复短文本列边框提前结束、长文本列继续延伸造成的断层与空白格。
- 一列和两列表格自动适配正文宽度。
- 三列及以上表格保持最小列宽，并继续支持整表横向滚动。

## 升级

已安装 v0.3.1–v0.6.5.8 的设备可以直接覆盖安装，不需要清除数据。
