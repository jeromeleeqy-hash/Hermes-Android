# Hermes Android 3.8.7

2026-10-05，基于完整 3.8.6 源码。版本 3.8.7 / 387，沿用原包名和签名覆盖安装。

## 事项完成后自动更新

此前完成事件主要重新读取概览 JSON；如果聊天中的进展尚未写回概览，首页仍显示旧卡片。现在从卡片进入聊天时，App 保存这个会话与卡片的关联。本轮完成后，后台结合刚完成的消息和相关记录同步此事项，再读取核对后的概览。已经执行写入的卡片按钮操作也会立即重新读取结果；实时完成与断线恢复使用同一条完成路径。

连续完成的更新短暂合并；上一轮首页同步还在执行时，新的进展等待一次后续同步。不会重做聊天里的业务操作，不会把普通讨论或回复结束当作事项完成。仍需实际写入回执确认结果；更新失败时保留原卡片和处理入口。

关联按服务器、账户、Profile、工作区和会话隔离，重开对话后仍可继续使用。同步任务从手机普通会话列表隐藏，保留在“任务”记录中；PC 端记录保持现有行为。同步不会切换页面、挤掉当前对话或清空未发送草稿。普通聊天不会每轮新建首页整理任务，手动刷新仍可结合最近普通聊天。

## 自然的事项讨论

事项聊天附件保留必要背景、来源、已记录信息和相关选项，移除布局与操作协议细节。不再让这轮对话同时承担首页 JSON 和回执维护；首页同步由独立后台流程负责。

提示沿用 Hermes 与用户平时的语气，默认先简短说明当前理解与下一步，根据用户需要再详细展开。核对差异时不使用训导式纠错开场，明确区分已核实事实、推测和建议；没有证据不能把相关性说成确定原因。用户明确要求的原记录更新仍遵守工作区既有规则，成功核对后才报告完成。

## 手动重命名

“回看”中长按对话 → 重命名 → 手动输入 → 保存。输入框预填原名，空白不能保存，最多 120 个字符。直接修改当前 Profile 的服务器标题，不请求 AI 生成名称，不把长名称强制压缩到 15 字，不丢失标点。列表空间不足时仍使用视觉省略。

已手动命名的对话保留名称偏好，后续标题整理不会把它重新生成。日常助理对话改名后仍绑定原会话。换设备时普通会话名称来自服务器；日常对话本机绑定被清除后，原固定名称检索不一定能找到手动改名的日常对话。

## 首页信息区

“为你留意”成为独立标题，数量显示为小标记。更新时间使用设备时区，放在次要位置；刷新使用带图标的清晰按钮，更新中显示状态并防止重复提交。数量、标题和操作分开排布，兼容三套外观和大字号。

移除“已结合最近进展核对首页”常驻成功提示。处理中、需要确认或结果不完整时显示紧凑的处理入口；成功后自动收起。失败详情仍可进入查看，不会隐藏实际错误。

## 升级范围

新聊天提示和同步关联从本版新打开的卡片对话开始生效。旧版本已创建且没有卡片关联的普通对话仍可使用手动刷新；从首页卡片重新进入后会建立新关联。

本次不改变持久首页协议、writer 或 Cron 模板（保持 3.8.4），无需重新配置早晚整理或执行文件收纳。自动同步需要可用网络与 Agent，通常稍候完成，并非本地即时修改卡片。App 在后台时暂缓发起新同步，回到前台后继续；尚未发出的合并队列只保存在内存，强制结束 App 后可用首页刷新核对，运行中的聊天按已有恢复机制处理。

构建和模拟网关验证见 [VALIDATION-3.8.7.md](../../VALIDATION-3.8.7.md)。真实 Agent 的措辞、写回耗时和手机厂商后台行为需安装后核对。
