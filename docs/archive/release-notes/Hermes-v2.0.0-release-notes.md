# Hermes Android v2.0.0

本版本把已确认的高保真 Demo 全量落地到 Android App，并保留现有 Hermes Agent、会话、语音、空间、任务和设置能力。

## 视觉与交互

- 全面采用清爽办公视觉基线：纯净表面、清晰文字层级、紧凑菜单和低干扰分隔线。
- 重建浅色与深色配色体系，中性色承担主体内容，高饱和颜色只服务主操作和状态语义。
- 液态玻璃集中用于导航、输入器、弹层和重点面板，长列表与正文继续平铺，避免卡片套卡片。
- 首页、聊天、空间、任务和我的五类核心体验采用统一圆角、间距、图标尺寸、底板与选中状态。
- Hermes Light 多彩图标继续保留，避免全单色造成单调，同时显著减少大面积彩色色块。

## 核心页面

- 会话首页增加明确的最近对话区、搜索和唯一主操作，筛选器与下拉菜单更紧凑。
- 聊天采用助手文档流、柔和用户气泡和更清晰的执行/审批/产物卡；输入器仅高亮发送动作。
- 空间使用高密度文件与产物列表；任务统一待处理、运行、定时和执行记录的状态表达。
- 我的与二级设置使用分组白色表面、细分隔线和更轻的标题，网关与语音页面同步更新。

## 兼容性

- 版本号：`2.0.0-debug (200)`。
- 最低 Android 8.0（API 26），目标 Android 16（API 36）。
- 延续固定 Debug 签名，可覆盖安装此前使用相同签名的版本。
