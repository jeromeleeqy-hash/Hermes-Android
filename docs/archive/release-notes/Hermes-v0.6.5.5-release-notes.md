# Hermes 0.6.5.5

本版本针对 Android 16 真机日志中的头像权限闪退做了结构性修复，并进一步增加桌面图标安全留白。

## 修复

- 头像不再交给 `ImageView` 延迟读取系统相册 URI，而是在后台线程内完成受保护的数据流读取与位图解码。
- 系统相册授权失效、图片被移动、URI 不可访问或图片数据损坏时，自动显示默认用户/Hermes 头像，应用主界面继续正常运行。
- 新选择的头像继续复制到应用私有目录，不依赖系统相册临时权限。

## 图标

- 桌面自适应图标的人物主体缩小到 432 px 画布中的 230 px，约占 53%。
- 白色外底与浅蓝装饰保持不变，为 OnePlus 等会额外放大自适应图标前景层的桌面保留更大的裁切安全区。

## 升级

已安装 v0.3.1–v0.6.5.4 的设备可以直接覆盖安装。旧头像失效时无需清除应用数据；安装后进入“我的 → 个人资料”重新选择头像即可迁移。
