# Hermes Android v0.6.5.1

本版本优化底部导航、会话列表标题区和应用启动过渡。

## 更新内容

- 底栏图标增大、标签文字缩小，层级更清楚。
- 未读对话会在底栏“对话”图标右上角同步显示红点。
- 会话列表左上角 Hermes 头像增大，昵称收紧；昵称和网关状态两行与头像等高对齐。
- Android 12 以后无法取消系统启动窗口，本版本移除了窗口中央的 Hermes 图标，并让明暗背景与应用首屏一致，降低独立启动页的存在感。

## 构建信息

- 版本：`0.6.5.1-debug`（versionCode 31）
- 最低系统：Android 8.0（API 26）
- 目标系统：Android API 36
