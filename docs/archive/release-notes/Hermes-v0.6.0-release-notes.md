# Hermes Android v0.6.0

## 本次升级

- 重新统一清爽办公和轻透毛玻璃两套皮肤。清爽版减少阴影、边框和重复卡片，毛玻璃版只在悬浮层使用透明材质、高光和柔和阴影。
- 统一页面边距、圆角、字号、行高、表单与触控尺寸，完善浅色和深色模式的语义颜色。
- 对话页改为“用户气泡 + Hermes 全宽正文”，明显增加 Markdown、代码块和表格的阅读空间。
- 空间文件改为平铺列表，任务统计合并为一条状态摘要，“我的”页面移除低优先级版本统计卡。
- 底栏在清爽皮肤下使用贴底导航，在毛玻璃皮肤下使用悬浮玻璃 Dock。
- 本轮保留现有图标资源，只调整图标的使用密度；图标造型将在后续独立设计。

## 安装说明

- 包名：`com.qingyu.hermescompanion.debug`
- 版本：`0.6.0-debug`（versionCode 21）
- 使用与 v0.3.1–v0.5.6 相同的固定开发签名，可以直接覆盖安装。
- Android 8.0 及以上系统可安装。

## 建议验证

1. 分别切换清爽办公和轻透毛玻璃，并检查浅色、深色两种模式。
2. 打开包含标题、表格和代码块的长会话，确认 Hermes 回复拥有足够阅读宽度。
3. 检查会话、空间、任务和“我的”四个主页面的标题、左右边距和底栏是否一致。
4. 打开远程网关、模型设置、语音设置和个人资料，确认表单高度与设置行密度统一。
5. 弹出输入法、斜杠命令、附件面板和助理面板，确认输入器始终贴合键盘且玻璃皮肤层级清晰。
