# Hermes Android v1.7.0

这是 UI 2.0 的第一阶段版本，重点不是增加更多功能，而是统一视觉语言、降低界面重量，并为后续首页、聊天、空间和任务页重构建立稳定基础。

## 本次更新

- 全面调整字体、字号、行高、间距、圆角和语义色，菜单与设置文字更轻、更紧凑。
- 清爽办公减少图标底板、彩色胶囊、阴影和重复卡片，会话与设置列表更平整、更高效。
- “圆润卡片”升级为“液态玻璃”，加入柔和透光表面、渐变细描边、轻阴影和低饱和环境光晕。
- 优化首页 Profile 菜单、操作菜单、筛选器、会话图标、项目分区与底部导航。
- 优化“我的”页面头像卡、网关状态、设置分组、主题选择器及深色模式可读性。

## 后续计划

下一阶段将集中重构首页与聊天核心体验，然后依次升级空间/任务、设置/弹层，最后完成真实背景模糊、动效、无障碍和性能收口。
