# Hermes 3.6.0-preview

2026-09-09 · 版本号 360 · Android 8.0 及以上

## 安装与使用

直接安装 `Hermes-3.6.0-preview.apk`，覆盖已安装的 3.5.1 预览版即可。包名和签名沿用原预览版，无需卸载，既有连接、日常对话绑定、界面偏好与草稿继续使用。

- 切换风格：**我的 → 设置 → 外观**。三套皮肤可分别搭配浅色、深色或跟随系统。
- 管理提示词：**对话 → ＋ → 提示词片段 → 管理**。
- 减少动画：**我的 → 设置 → 外观 → 减少动态效果**。

## 本次升级

| 范围 | 结果 |
| --- | --- |
| 三套首页 | 温暖版左右分栏与并排卡片；玻璃版居中人物和透光操作区；安静版半身人物和细线列表 |

## 源码与构建

源码包含完整工程、动画资源、静态后备图、测试、界面规范和本轮实际渲染图；不包含签名私钥、个人连接配置或构建缓存。

```sh
./gradlew -PhermesPreview=true -PhermesSigningFile=/absolute/path/to/preview.keystore :app:testDebugUnitTest :app:assembleDebug
```
