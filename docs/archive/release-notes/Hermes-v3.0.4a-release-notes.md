# Hermes 3.0.4a 修复说明

## 修复内容

1. 新对话的运行会话已创建，但数据库中可能尚未保存它。App 现在直接展示已知为空的实时会话，在尚未发送消息时重新打开也不会提前请求历史。真正的历史会话读取失败仍会正常显示错误。
2. 离开原会话后才返回的历史读取错误不再影响正在查看的其他会话。
3. 删除、归档等普通提示停留约 1.5 秒；错误提示继续保留较长的阅读时间。
4. 全局运行状态条移到 Scaffold 底部布局，实际预留高度。会话列表和新建按钮位于运行状态条上方，不再被覆盖。

## 安装

测试包名保持 com.qingyu.hermescompanion.debug，版本 3.0.4a-release-debug，versionCode 306。
沿用上次 Hermes-3.0.4-test.apk 的测试签名，可直接覆盖该测试版并保留数据。它不能覆盖原正式版；原正式版仍需要原发布签名。

## 手机验收

- 在“全部项目”中新建空对话，确认没有 Session not found；返回列表后再次打开，确认仍无误。
- 在指定项目中新建对话，确认目录正确，并发送第一条消息。
- 让会话 A 持续运行，返回列表，确认右下角新建按钮可见、可点击；新建 B 并发送，确认两段会话分别生成。
- 点击运行状态条或“停止”，确认原有入口仍可用；任务完成后列表正常恢复高度。
- 删除普通会话，确认提示约 1.5 秒消失；连续进行不同操作时提示不长期排队。
- 用较大系统字体重复运行栏和新建按钮检查。

## 验证范围

自动测试和 APK 构建结果见同包 VALIDATION-3.0.4a.md。没有在真实 Android 手机或用户实际网关上完成上述验收，仍需安装后确认。
