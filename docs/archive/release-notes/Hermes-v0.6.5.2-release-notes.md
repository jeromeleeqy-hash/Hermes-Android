# Hermes Android v0.6.5.2

本版本更新应用图标，并统一会话列表首页的 Hermes 身份显示。

## 更新内容

- 使用棕发、青色耳机的 Hermes 新形象作为应用图标，优化轮廓、光影和深蓝背景。
- 为 Android 自适应图标提供独立安全区构图，兼容圆形、圆角矩形与异形桌面蒙版。
- 更新系统主题单色图标为人物与耳机轮廓。
- 会话列表左上角读取个人资料中上传的 Hermes 头像；没有上传时显示内置图标。
- 缩小 Hermes 昵称与网关在线状态之间的间距。

## 构建信息

- 版本：`0.6.5.2-debug`（versionCode 32）
- 最低系统：Android 8.0（API 26）
- 目标系统：Android API 36
