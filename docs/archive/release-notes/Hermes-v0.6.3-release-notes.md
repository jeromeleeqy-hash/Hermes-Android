# Hermes Android v0.6.3

本版本完成全软件图标系统升级，采用用户选定的底栏「对话」C 方案作为统一母版。

## 图标升级

- 重绘 29 个应用语义图标，覆盖底栏、对话、空间、任务、设置、文件操作和全部相关弹窗。
- 重点精修对话、空间、任务、我的、AI、模型、新对话、项目、搜索、附件和麦克风等高频入口。
- 删除无功能圆点、随机色块、装饰角标，避免小尺寸显示混乱。
- 简单操作统一使用圆角线性图标、主题色和一致的视觉重量。
- 应用启动图标、应用内 Hermes 标志和通知栏小图标同步更新。
- 深色模式使用专用高亮色板，白色信息镂空保持清晰。

## 构建信息

- 版本：`0.6.3-debug`（versionCode 24）
- 最低系统：Android 8.0（API 26）
- 目标系统：Android API 36
- 13 项单元测试全部通过
