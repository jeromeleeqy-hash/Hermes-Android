# Hermes Android 2.4.0

发布日期：2026-08-16

本次升级继续沿用 Telegram 式清爽办公方向，重点校正完成状态层级，并把“我的”从设置集合重建为真正的个人主页。

## 界面与交互

- 聊天执行结束后只显示一行小号“本轮执行完成”，与助手正文左边缘对齐；移除绿色矩形卡、重复正文和过大的对号。
- 首页下拉选单字号与筛选框统一，保持选项文字靠左、选中对勾靠右。
- “我的”页面只保留头像、姓名状态和“设置照片 / 编辑信息 / 设置”三个核心按钮；版本、Agent 和网关摘要移到主页下方。
- 点击“设置”进入独立纯设置列表，不再重复显示头像和个人信息。
- 点击圆形头像会以缩放淡入进入顶部沉浸式照片视图，保留三个资料操作按钮和连接摘要。
- 新增应用内使用说明，集中解释对话、助理面板、空间、任务、语音与连接安全。

## 照片与兼容性

- 恢复系统照片选择和裁剪；所选图片会复制到应用私有目录，不长期依赖相册 URI。
- 编辑昵称或签名时不再清除已保存头像。
- 保留现有 Gateway、聊天、语音、会审、空间、任务和全部设置能力；继续使用固定开发签名，可直接覆盖安装 v0.3.1 之后的版本。
