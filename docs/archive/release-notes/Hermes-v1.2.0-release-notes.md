# Hermes Android v1.2.0

这一版重点打通手机端的“结果回看”链路：对话里生成的内容能够在空间集中找到，文件和来源会话可以互相返回；同时补上真正可用的消息正文搜索和连接诊断。

## 新增

- 最近产物：空间页新增独立入口，自动汇总当前 Profile 对话中的 Markdown、图片和其他文件。
- 来源定位：产物可返回生成它的会话；从最近产物打开 Markdown 后，可继续定位到对应消息。
- 消息正文搜索：搜索最近 100 个会话、每个会话最近 200 条消息，结果展示命中片段。
- 搜索定位：点击消息命中结果后进入对应会话，并高亮显示目标消息。
- 连接诊断：分别检查网关响应、登录 Cookie、WebSocket 实时通道、Profile 与会话接口。

## 产品取舍

- 不增加扫码配对。当前场景使用固定的 Hermes Desktop、WebUI 与手机 APP，扫码不会减少日常操作，反而会增加入口和连接状态管理。
- 不新增重复的任务主导航。现有任务页已具备进行中、定时任务和执行记录分类，本版继续沿用。

## 兼容说明

- 消息正文搜索基于当前 Hermes 网关已有的会话与消息接口，不要求新增服务端协议。
- Android 8.0 及以上，版本号 `1.2.0`，`versionCode 120`。
