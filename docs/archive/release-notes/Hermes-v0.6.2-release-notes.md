# Hermes Android v0.6.2

本次版本针对 v0.6.1 的主页面布局反馈继续打磨，重点修正固定区域、分段栏宽度、列表阅读节奏与任务操作位置。

## 界面调整

- “我的”顶部个人资料改为固定主卡，滚动设置内容时头像、昵称和签名始终保留；点击主卡即可编辑资料，设置列表不再显示重复入口。
- “最近 / 项目”切换恢复全宽、居中布局，仍保持紧凑高度和较小字号，避免重新变得突兀。
- 会话标题缩小一级，列表行距、标题与摘要间距以及首尾留白适度增加。
- 任务页将“刷新”和“新建任务”放进任务概览卡底部，采用同宽次要/主要操作，取消孤立的右上角图标按钮。

## 构建信息

- 版本：`0.6.2-debug`（versionCode 23）
- 最低系统：Android 8.0（API 26）
- 目标系统：Android API 36
