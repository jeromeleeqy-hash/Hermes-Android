# Hermes Android v0.8

v0.8 集中优化日常聊天可靠性和会话管理，不包含消息正文全文搜索，也不包含长回复工具/推理过程折叠。

## 主要变化

- 未发送文字会按 Profile 和会话自动保存，重新进入会话即可恢复。
- 发送失败时恢复文字与附件，并提供“重新发送”。
- 阅读长会话时可随时“跳到底部”；流式输出不会强制拉走当前阅读位置。
- 会话首页可按当前 Profile、项目以及今天、近 7 天、近 30 天筛选。
- Profile 被服务端删除或返回空列表时自动安全回退，切换期间显示明确状态。
- 用户头像和 Hermes 头像新增保存前裁剪，可调整缩放和位置。
- 本机配置读取、头像解码和 Profile 初始化增加故障隔离，继续保留启动崩溃报告与安全启动。
