# Hermes Android 2.3.0

发布日期：2026-08-16

本次升级继续沿用 Telegram 式清爽办公方向，重点减少聊天输入区的常驻操作，并为首页、个人资料、底部导航、分段控件和开关补齐统一、克制的动态反馈。

## 界面与交互

- 专家会审移入聊天右上角助理面板；输入区常态只显示附件、命令和语音，输入文字或加入附件后，右侧语音键自动切换为圆形发送键。
- 首页下拉选单改为文字左对齐、选中对勾右对齐；新建对话按钮缩小为 48 dp 圆形，保持单手可达并减少对列表内容的遮挡。
- “我的”页面点击头像后进入独立个人资料视图，以圆形大头像、渐变顶部区域和缩放淡入过渡建立更清晰的资料/设置层级。
- 底部导航选中底板会在四个入口间平滑滑动，图标颜色与尺度同步变化。
- 空间、任务和高级设置共用弹性滑动分段控件；通知、定时任务及高级设置开关统一主题轨道和弹性尺度反馈。

## 兼容性

- 保留现有 Gateway、聊天、语音、专家会审、空间、任务、通知和服务端设置能力。
- 暂不重绘图标，仅调整入口结构、尺寸与交互状态；完整图标升级留到下一轮统一处理。
- 使用与 v0.3.1 以后版本一致的固定开发签名，可直接覆盖安装。
