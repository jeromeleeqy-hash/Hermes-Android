# Hermes Android v0.6.5.3

本版本将用户确认的浅色扁平 Hermes 形象正式接入应用图标系统。

## 更新内容

- 桌面图标改为白色底、浅蓝不规则装饰衬底的棕发耳机 Hermes 形象。
- 人物肤色轻微降低暖度，整体视觉更清爽，并与 Hermes Light 图标体系保持一致。
- 圆形、圆角矩形和异形自适应图标使用独立安全区构图，避免不同桌面裁切关键人物轮廓。
- 应用内置 Hermes 图标和高分辨率备用资源同步更新。

## 构建信息

- 版本：`0.6.5.3-debug`（versionCode 33）
- 最低系统：Android 8.0（API 26）
- 目标系统：Android API 36
