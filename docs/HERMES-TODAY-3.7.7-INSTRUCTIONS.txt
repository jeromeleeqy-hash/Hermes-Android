Hermes Android 3.7.7 安装与使用

一、覆盖安装
下载 Hermes-Android-3.7.7-release.apk 后直接安装到现有 App 上，保留当前安装和数据。此包沿用 com.qingyu.hermescompanion.preview 及此前的签名，版本号为 377 / 3.7.7。

二、更新服务器卡片规则与早晚任务
进入首页右上角“⋯” → “早晚整理”。
确认早间时间、晚间时间和时区（国内通常为 Asia/Shanghai），点击“交给 Hermes 配置”。
这会发起一次真实配置对话，把新规范、脚本和模板交给自己的 Hermes，升级旧卡片并配置对应的早晚任务。配置过程可能需要几分钟。

配置对话结束后，再进入“早晚整理”，点击“核对已配置的任务”。应能看到两条真实任务 ID、启用核验和服务器返回的下次运行时间。若提示任务缺失、暂停或不匹配，请查看原配置对话，不能仅根据一句“已配置好”判断完成。

三、查看和操作卡片
回到首页，点同步按钮。选择一张确认、清单或记录类卡片，填写或选择内容后提交。简单操作会在卡片中显示处理过程，收到服务器写回回执后显示结果。
“查看处理详情”用于查看 Agent 的实际处理；“聊一聊”用于进一步讨论。
如果提示卡片已变化，旧输入会保留，请核对后载入新内容。结果未确认时先同步核对，不要反复另起新操作。

四、关于旧内容
升级 App 后，服务器已有 JSON 不会自动变成新卡片；需要完成第二步配置。此前写在卡片里的错误日期、含糊指代或事实冲突，仍需要 Hermes 根据原始资料核对，不能靠换 UI 自动纠正。

五、网络问题
本版修正前后台切换、延迟心跳导致的误超时，并保留最近连接诊断。若手机上仍出现异常，在“我的”的连接诊断中查看最近记录，并附上当时是否刚解锁或切换 Wi-Fi/移动网络，便于继续定位。
