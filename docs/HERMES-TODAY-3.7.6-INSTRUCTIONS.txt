Hermes 3.7.6 安装与使用

1. 覆盖安装 Hermes-Android-3.7.6-release.apk，不要卸载原 App。
2. 首页卡片和分类按钮已统一样式；点击决定卡进入详情再回应。详情顶部“关闭”返回，正文可独立滚动。
3. 要让服务器已有卡片变得好懂：打开首页右上角“…” → “修正卡片与整理规则”。会直接启动处理对话，由 Hermes 根据本次附件补足背景、拆分问题，并核对更新已有对应概览 Cron 的整理规则。
4. 看处理对话中的回读结果。它应保留已有任务时间、时区和启用状态，不创建重复 Cron；不能匹配的任务应跳过并说明。任务未完成或失败时，新版 App 仍显示原有数据，不能当作规则已生效。
5. 如仍报连接错误：在“我的 → 设置 → 远程网关 → 诊断与 Agent 版本”运行诊断，查看“最近的连接记录”。保留发生时间和具体错误，说明当时使用 Wi-Fi 或移动网络；本版不再仅以一句“网络不稳定”描述所有请求问题。

安装本身不会写入服务器或修改 Cron。手机保留加密副本，服务器 JSON/Markdown 仍为正式记录。连接修复已用模拟中断与并发测试验证，真实设备网络仍需观察。
