# Hermes Android 产品规划

## 产品定位

Hermes Android 不是 WebUI 的完整复制，而是个人日常使用的轻量原生入口。APP 聚焦沟通、查看进度、发送资料和常用自动任务；模型密钥、工具集、Skills 和高级服务器管理继续由 Hermes Desktop、WebUI 或 CLI 负责。

## 当前版本（3.0.0）

已形成以下移动端闭环：

1. 使用与 Hermes Desktop 相同的远程网关、用户名和密码登录。
2. 查看、继续、新建和删除服务器会话。
3. 通过文字、系统语音识别、图片或文本资料发起任务。
4. 通过网关 WebSocket 实时看到回复和工具状态。
5. 中断不再需要的长任务。
6. 退出后使用加密 Cookie 恢复登录和会话历史。
7. 浏览当前 Hermes 项目空间，在 APP 内预览、编辑并保存 Markdown 文档。
8. 在当前聊天中切换模型，并集中查看聊天产物与 Hermes 待办。
9. 隐藏原始工具输出、优化长会话加载，并自动同步精简后的会话标题。
10. 使用 Hermes 原生项目整理会话，并支持 AI 重命名、置顶和归档。
11. 在统一配色和资源级多色图标下提供单一 Telegram 式轻量界面，保留浅色、深色和跟随系统模式。
12. 在空间和聊天中预览图片，并通过真实接口管理 Hermes 定时任务。
13. 使用安卓系统通知接收对话结果和定时任务状态，按需启用声音、振动与桌面角标。
14. 在独立设置页管理语音识别语言和识别后发送方式，并查看完整客户端版本说明。
15. 使用 WebSocket 心跳维持移动网络连接；流式回复断线后自动重连并从服务器同步生成结果，不重复提交用户消息。
16. 使用统一的页面边距、字号、表面层级和语义颜色，保持全应用一致的信息结构。
17. 将助手回复升级为全宽文档式排版，并减少空间、任务和设置页中的重复卡片与装饰层。
18. 固定“我的”个人资料主卡，统一主页面分段栏宽度、列表留白和任务操作区布局。
19. 离开聊天页后继续在 ViewModel 生命周期中生成回复，完成后发送系统通知并标记会话未读。
20. 用户与 Hermes 使用独立昵称和可更换头像；图片只从应用私有目录读取，聊天列表顶部使用 Hermes 资料及网关状态。
21. 在移动端切换并记住 Hermes Profile，各 Profile 的会话、项目、设置和缓存互相隔离。
22. 使用 79 枚 Hermes Light 多色图标，并为未激活底栏图标保留灰度层次。
23. 聊天中的 Markdown 文档地址升级为整卡点击并进入 APP 内预览。
24. 聊天中的 `@image:` 和标准 Markdown 图片地址异步加载为内联缩略图。
25. 从聊天打开 Markdown 或图片后，可通过页面按钮或系统返回键直接回到原对话。
26. Markdown 表格按每行最高单元格统一行高，减少长文本造成的边框断层。

## 页面结构

### 连接与设置

- 远程网关 URL
- Hermes 用户名和密码
- HTTP 风险确认
- 登录会话恢复
- 浅色、深色、跟随系统
- 单一 Telegram 式轻量界面，支持浅色、深色与跟随系统
- 全局统一多色矢量图标
- 清除本机连接

### 会话首页

- 服务器连接状态
- 高密度会话列表与下拉刷新
- 真实会话摘要、中文相对时间与 Cron 会话折叠
- 最近 / 项目两种展示方式
- 顶部品牌信息与最近 / 项目切换固定显示
- 标题左侧黄色置顶标识
- 右上角菜单新建、搜索或批量 AI 重命名对话
- 长按列表项进行 AI 重命名、置顶、归档、移至项目或删除

### 空间

- 优先识别当前 Hermes 项目主目录
- 浏览服务器目录与文件
- Markdown 文档原生预览
- Markdown 基础编辑、保存与未保存修改提醒
- 系统返回手势按文档、目录层级逐级返回
- 图片文件全屏预览、双指缩放和拖动

### 聊天页

- 最近 60 条历史消息首屏、向上翻页、缓存与按帧合并的流式回复；搜索独立覆盖最近 200 条
- 独立斜杠命令面板与一次性专家会审（真实 Delegation / MoA，不展示原始互聊）
- 工具状态摘要，不展示原始 JSON、diff 或命令输出
- Markdown、代码和表格
- 多行输入、语音转文字与快捷提示词
- 图片/文本附件、链接与项目空间快捷入口
- 当前会话模型切换
- 聊天产物和待办汇总
- Hermes 自动标题同步，最多 15 个字符
- 发送和停止
- 聊天图片、图片产物和待发送附件直接预览

### 定时任务

- 读取服务器 Cron Jobs
- 新建任务与 Cron 表达式
- 暂停、恢复、立即运行和删除
- 下次执行时间与最近状态

### 通知与语音

- 安卓通知权限、消息弹窗、提示音、振动与桌面角标
- 定时任务 15 分钟后台补偿检查
- 语音输入启停、识别语言与识别后自动发送

## 安全原则

- 密码仅用于登录，不在本机持久化。
- 登录 Cookie 使用 Android Keystore 管理的 AES-GCM 密钥加密。
- HTTP 连接必须由用户明确确认风险。
- 公网部署推荐 HTTPS；用户名密码网关推荐置于可信局域网或 VPN。
- APP 不保存模型供应商密钥，也不把凭据写入源码或日志。

## 当前边界

- 仅支持网关的用户名密码提供方；OAuth 登录后续适配。
- 单用户个人使用，不做账号注册体系。
- 只提供移动端常用 Hermes 设置、Skills、工具集和 MCP 开关，不提供任意服务端配置文件编辑器。
- 不支持 PDF、Word、Excel 原始文件上传。
- 不实现本地完整会话数据库，以服务器记录为准。
- 不提供厂商云推送；当前通知来自正在运行的对话及系统后台定时补偿检查。
- 已实现审批 / 澄清卡片与跨进程恢复；仍不提供前台常驻服务。

## 后续阶段

### 0.5 真机体验

- 真实阿里云网关兼容性与断网重连
- 图片压缩和拍照入口
- PDF、Word、Excel 处理
- 会话复制和分享
- 进行中任务恢复

### 0.6 助理能力

- 审批、澄清和授权交互卡片
- Skills 快捷入口与会话级参数设置
- Hermes OAuth 远程网关登录

### 后续发布强化

- 正式签名与升级机制
- 生物识别解锁
- 崩溃与性能监控（默认不上传聊天内容）
- 隐私说明和正式分发

## 当前验收基线（1.0）

- 能使用远程网关 URL、Hermes 用户名和密码完成登录。
- 能列出并进入电脑端已有会话。
- 能创建会话并完成至少三轮连续对话。
- 文字回复逐步显示，工具状态可见，停止按钮有效。
- 图片输入和常见文本附件可被 Hermes 读取。
- 密码不持久化，Cookie 不以明文出现在 SharedPreferences。
- HTTP 地址必须明确确认；HTTPS 地址无需额外确认。
- 首页可下拉刷新，并能通过右上角菜单新建或搜索会话。
- 会话列表不显示无意义占位文案或原始时间戳，Cron 会话默认折叠。
- “空间”可进入当前项目、浏览目录、预览并编辑 Markdown 文档。
- 输入法弹出后输入框紧贴键盘上沿，不出现重复避让空白。
- 聊天正文不显示原始工具或系统消息；工具运行详情集中在任务页，聊天页不重复展示整理进度。
- 长会话仅加载最近一页并居中显示加载状态，进入后直接定位到最新消息。
- 会话列表使用马卡龙图标而非文字首字头像。
- 助理面板可切换当前会话模型，并查看聊天产物与 Hermes 待办。
- 空间图片、聊天图片和图片附件可在 APP 内打开并缩放预览。
- 定时任务可读取、新建、启停、立即运行和删除，失败时展示真实错误。
- 安卓通知权限、测试通知、声音、振动和角标设置可用。
- 语音输入可以选择识别语言和是否自动发送，“关于”页面显示当前真实版本。
- 新会话标题由 Hermes 自动总结后同步，最终标题不超过 15 个字符。
- 聊天加载状态居中且没有白色卡片背景，输入框不会被输入法遮挡。
- 长按会话可以 AI 重命名、置顶、归档、移至 Hermes 项目或删除。
- 首页可以在最近会话和项目分组间切换，并支持批量 AI 重命名。
- 模型列表滚动到底不抖动，空间中的系统返回手势优先返回上一级。
- 可在“我的 → 外观”切换浅色、深色或跟随系统，重启后保持选择。
- 会话列表滚动时顶部品牌信息、菜单和最近 / 项目切换不移动。
- 置顶标识为标题左侧的黄色新图形，底栏和设置入口使用统一多色图标。
- 全局使用克制的圆角、低对比边界与轻阴影；沉浸式头像仅在照片下半段使用渐变模糊。
- 手机网络短暂抖动后能自动重新连接并取回服务器回复，不显示底层英文异常或空白助手气泡。
- 底栏、首页菜单、列表、项目、任务、聊天快捷操作和“我的”页面使用同一套资源级多色填充式矢量图标。
- 图标在浅色与深色模式下保持清晰，造型和语义色不发生割裂。
- 图标不依赖细描边，在小尺寸下仍保持清晰的实心轮廓、双色层级和可识别语义。
