# Hermes mobile: quick start

1. Install Hermes-3.6.3.apk. This stable Release build updates the existing preview app signed with the same key and retains its settings.
2. Watch or skip the welcome animation. On the identity setup screen, tap **中 / EN → English**. Choose your local assistant name and avatar, then continue to gateway setup. Existing installations keep their profile and can change language in **Me → Settings → Language**.
3. Enter the gateway URL and the same Hermes username and password used on your computer, then connect.
4. **Assistant → Talk to me** opens your daily conversation. **History** lists conversations, **Tasks** shows running and scheduled work, and **Files** opens workspace files and outputs.
5. To create a project, choose **History → Recent → Projects → New project**. Enter a name and the absolute folder path on your Hermes server, for example `D:\Hermes\workspace`, `\\server\share\workspace` or `/home/user/workspace`. You can browse the folder before creating the project.
6. **Me → Settings → Appearance** switches between Warm, Glass and Quiet skins, light/dark modes, and reduced motion.
7. In a conversation, **+** adds files, images, commands, workspace files or a prompt snippet. **Manage** lets you edit snippets. Selecting a snippet inserts it into the draft for review.
8. The conversation menu offers **Full conversation**, **Assistant settings** and **Voice chat**. UI language and the Agent's configured speech/model preferences are separate settings.

Your existing messages, custom snippets, filenames and server content keep their original text when switching UI language.

For step-by-step help, open **Me → User guide**. Browse the six categories or search by task. See also [Task guides](OPERATION-GUIDE.en.md).
