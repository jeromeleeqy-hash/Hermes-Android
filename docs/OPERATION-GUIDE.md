# Hermes 常用操作指南

## 开始与连接

首次使用、更换网关、连接排查

### 第一次连接 Agent

1. 首次打开后观看或跳过开场动画，在“认识彼此”里选择助理头像、填写助理昵称和你的称呼。
2. 点击“下一步 · 连接网关”。在电脑端远程访问设置中复制远程 URL，填写到手机的服务器地址。
3. 填写电脑端设置的网关用户名和密码，点击“验证并连接”。成功后进入助理页。

昵称只改变手机上的显示，不会更改 Agent、Profile 或网关账号。

### 更换服务器或重新登录

1. 进入“我的 → 设置 → 远程网关”。
2. 修改服务器地址或用户名，重新输入密码。
3. 点击“验证并更新连接”，等待成功提示。需要退出当前连接时，使用页面底部的“清除连接并退出”。

清除连接会退出网关；手机里的昵称、头像和外观选择会保留。

### 连接失败时怎么排查

1. 核对完整远程 URL，确认没有额外追加 /api 或 /v1；点地址下方“在哪里找到地址？”可查看填写方法。
2. 确认服务器和网关正在运行，手机能访问该地址，再核对用户名、密码。
3. 已经保存过连接时，展开“诊断与 Agent 版本”，点击“诊断当前连接”，按失败项目处理后重试。

## 日常对话

开始新对话、查找记录、添加资料

### 开始或继续一段对话

1. 在助理页点击“跟我说”，进入日常助理对话；也可以点“接着上次的事”里的记录继续聊。
2. 想开启独立话题时，进入“回看”，点击右上角的新建按钮。
3. 在输入框写下需求并发送；右上角“⋯ → 完整对话”可以查看前后文。

### 查找以前的对话

1. 进入底部“回看”，点右上角放大镜，输入标题或记得的关键词。
2. 需要缩小范围时，回到列表，使用项目和时间筛选。
3. 点开结果后选择“完整对话”，向上滚动查看更早的消息。

### 把文件或图片交给助理

1. 在对话输入框左侧点击“＋”。
2. 选择“文件”或“图片”从手机添加资料；选择“空间”可以挑选服务器上的文件。
3. 确认资料已经出现在输入区，再补充你希望如何处理它，最后发送。

### 设置自己的提示词片段

1. 在对话中点击“＋”，找到“提示词片段”，点击旁边的“管理”。
2. 新增或编辑片段，填写名称和正文后保存；也可以调整顺序或删除不再使用的片段。
3. 返回添加面板，点一个片段将内容放入输入框，检查并修改后再发送。

## 语音交流

语音输入、连续语音、识别排查

### 用语音补充一句

1. 进入“我的 → 设置 → 语音设置”，确认“启用语音功能”已打开。
2. 回到对话，点击输入框旁的语音按钮，首次使用时允许麦克风权限。
3. 说完后结束录音，检查识别出来的内容，再按页面提示发送或继续对话。

### 开始连续语音并中途打断

1. 在对话右上角点击“⋯ → 连续语音”。
2. 允许录音后开始说话；助理回答时，按照页面上的打断按钮暂停它，再继续说。
3. 返回对话即可退出连续语音。停留在前台连续语音页面时，屏幕会保持点亮。

切到后台或退出语音页后，恢复系统正常息屏；手动锁屏仍然有效。

### 语音听不清或无法识别

1. 先到手机系统设置确认 Hermes 的麦克风权限已允许，并检查网络连接。
2. 进入“我的 → 设置 → 语音设置”，检查语音引擎和收音环境。
3. Agent 语音服务不可用时，可尝试自动或手机系统引擎，再用一句短话测试；中文转写形式可以在同页调整。

## 项目与文件

工作目录、预览编辑、分享文件

### 设置项目工作目录

1. 进入“回看”，在顶部视图筛选中切换到“项目”，点击“新建项目”。
2. 填写项目名称和服务器上的绝对工作目录，也可以点击“浏览目录”选择。
3. Windows 示例为 D:\Hermes\workspace；Linux 示例为 /home/user/workspace。确认后创建项目。

填写的是运行 Agent 的电脑目录，不是手机存储路径。

### 查看并编辑文件

1. 进入底部“文件”，选择目录并点开目标文件。
2. Markdown 等可编辑文本可以切换到编辑界面；修改正文后点击保存。
3. 返回列表前确认保存成功；不支持编辑的文件使用预览或下载功能。

### 分享助理生成的文件

1. 点击回答中的文件卡片，或到“文件”中找到对应文件。
2. 打开预览后点击分享按钮，选择目标应用。
3. 如果目标应用不能接收该类型文件，先下载文件，再从手机的文件管理器分享。

## 任务与审批

定时执行、查看结果、处理确认

### 建立每天执行的任务

1. 进入底部“任务”，点击新建按钮，填写任务名称。
2. 在“让 Hermes 做什么”中写清任务要求，再设置 Cron 表达式；每天 9 点可填写 0 9 * * *。
3. 点击创建，打开任务详情检查时间和内容；查看首次执行结果，再按需要调整。

执行时间取决于服务器任务调度所用时区，请核对任务详情。

### 查看结果或暂停定时任务

1. 在“任务”的定时列表中点开目标任务。
2. 查看最近运行状态和结果；需要立即验证时使用立即运行。
3. 暂时不用时关闭或暂停任务，之后可重新启用。

### 处理需要你确认的操作

1. 在“任务”的待处理项或对话中的审批卡片里打开请求。
2. 阅读将执行的操作和涉及内容，确认是否符合你的意图。
3. 选择允许或拒绝，再回到对话查看助理是否继续执行。

## 个人偏好

昵称头像、主题语言、长期记忆

### 更换助理昵称和双方头像

1. 进入“我的 → 编辑信息”。
2. 在“你的助理”中更换头像、修改昵称；在“你的信息”中修改自己的头像、称呼或签名。
3. 点击保存。助理页会显示“我是 + 助理昵称”，其他页面也使用更新后的资料。

### 切换主题或中英文

1. 进入“我的 → 设置 → 外观”，选择温暖、玻璃或安静风格。
2. 在同一面板选择浅色、深色或跟随系统；如果希望减少动态效果，可开启减少动画。
3. 返回设置，进入“语言”选择简体中文、English 或跟随系统。

语言切换只影响软件界面，不会自动翻译已有对话和服务器文件。

### 切换桌面图标

1. 进入“我的 → 设置 → 外观”，下滑到“桌面图标”。
2. 选择“白发伙伴”或“耳机精灵”，出现成功提示后返回手机桌面。
3. 桌面可能需要几秒刷新。切换只改变软件图标，不会修改对话里的头像。

图标选择会保留，下次打开和升级后无需重新设置。

### 点击人物播放互动动作

1. 在助理首页点一下白发女孩，播放一个互动动作。
2. 动作结束后再点，会播放另一款；播放中连续点击不会重新开始。
3. 如需静态人物，进入“我的 → 设置 → 外观”开启“减少动态效果”。

离开首页或切到后台会结束本次互动；Android 8 设备使用静态人物。

### 修改助理的长期记忆

1. 在“我的”页面打开“我的记忆”，先阅读当前内容。
2. 进入编辑，补充或修改需要长期保留的偏好与事实。
3. 保存后再次打开核对；若要调整人格与行为方式，使用“我的心智”。

这些内容属于当前 Agent Profile，与手机上的头像和昵称设置分开。
