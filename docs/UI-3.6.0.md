# Hermes 3.6.0 界面与交互规范

本轮依据最终确认的三套首页设计及 3.5.1 细节反馈实施。所有皮肤共享功能和状态，布局与材质随风格变化。

| 风格 | 首页结构 | 内容、控件与导航 |
| --- | --- | --- |
| 温暖灵动 | 左侧问候和操作，右侧全身人物；最近两段对话并排卡片 | 鼠尾草绿、柔和实体卡片，一体底栏 |
| 液态玻璃 | 居中问候和全身人物，独立透光按钮；最近两段对话集中排列 | 平缓低饱和背景、细高光、透明控件与悬浮底栏，正文近不透明 |
| 安静耐看 | 半身人物与问候并列；正文和操作靠前，最近对话用细线列表 | 近白或深灰背景、墨色、减少装饰容器，平面底栏与下划线 |

## 布局

- 首页两侧 22dp；信息页通常 16dp。组间 24dp，组内解释与标题保持接近。
- 温暖版在较窄屏幕或大字号下将并排卡片改为纵向，保留完整点击入口。
- 玻璃版人物与主按钮至少留 16dp；角色不覆盖按钮或其触摸范围。
- 选择项的长模型名、服务商与值分层排列；设置开关的说明文字占满一行可用宽度。
- 所有页面保留滚动能力，长内容可到达；编辑页面同时避让系统导航区与键盘。
- 底部弹层的表面一直绘制到窗口底端，导航安全区在表面内部留出。24dp 手势区与 48dp 导航区均有回归检查。

## 材质与组件

- 普通内容使用可读实体表面；玻璃感用于导航、弹窗和少量主控件。
- 页面层供跨窗口弹层及底栏取样；页面内主按钮只取样独立背景层，防止递归录制。
- 光学处理使用低强度模糊和浅边缘透镜，不绘制气泡、光环或大面积彩色高光。
- 图标底托、按钮圆角、选中状态与禁用状态跟随当前皮肤。图标尊重所在按钮的前景色。
- 单选项统一使用圆形 RadioButton；多选继续使用 Checkbox，开关保留完整触摸区域。
- 旧系统或没有光学取样能力时使用可读实体表面。

## 交互

- 首页品牌无弹出菜单，保留独立搜索；五个底部目的地保持原顺序。
- 对话菜单：完整对话、助理设置、连续语音。已进入完整对话时首项为“最新答复”，便于返回聚焦阅读。
- 添加到对话 → 提示词片段 → 管理：新建、编辑、上移、下移、删除、恢复默认。
- 点击提示词只插入现有草稿；已有文字保留，片段后续仍可编辑，不会自动发送。
- 删除及恢复默认需要确认；编辑未保存时关闭或返回会提供继续编辑选项。
- 自定义片段和减少动态效果保存在本机；无片段的空列表不会被默默重新填充默认内容。

## 人物与动态

使用已审核的透明 640×640 Animated WebP 原素材及对应 PNG 后备图。只在显示布局中去掉透明余量，不重画人物。

| 资源 | 使用位置 | 播放方式 |
| --- | --- | --- |
| 02 欢迎 | 首次进入温暖/玻璃首页、空对话 | 一次后切全身待机；同次应用会话首页不重复欢迎 |
| 01b 全身待机 | 温暖与玻璃首页、空对话 | 循环 |
| 01a 半身待机 | 安静首页、连续语音准备/朗读 | 循环；安静首页以腰部以上构图 |
| 03 聆听 | 连续语音与对话录音 | 真实监听状态循环 |
| 04 处理 | 语音识别/思考、对话运行状态 | 真实工作状态循环 |
| 05 完成 | 在当前对话观察到运行结束且收到新完成记录 | 一次；历史回复不会触发庆祝 |

解码在后台线程。离屏、切换页面或应用暂停时停播并释放动画引用。状态之间短暂淡入淡出，欢迎及完成不被强制设为无限循环。减少动态效果或系统禁用动画时使用 PNG；API 26–27 使用静态后备图。

真实音量仅控制收音按钮里的简洁波形；不添加持续闪烁装饰。功能内容可正常使用，不依赖动画播完。
