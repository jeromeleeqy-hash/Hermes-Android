Hermes Android 3.7.8 使用说明

1. 安装 Hermes-Android-3.7.8-release.apk，直接覆盖旧版本，不要卸载。
2. 无需重新创建早晚 Cron，也不用重新整理整个工作区。
3. 打开之前执行受阻的卡片，在详情底部选择“继续未完成部分”。
4. App 会先核对原会话和回执，再沿用原操作编号续做。若服务器仍在运行，请稍后核对，不要重复发起。
5. 若弹出审批，请阅读具体操作；同意这次操作可选择“仅本次允许”，再点“确认并继续”。
6. 服务器 JSON 写回并带有对应回执后，卡片才显示已确认。聊天中说“完成”不会被直接当成写回成功。

此次修复的是新版 Hermes 审批请求与 Android 客户端不兼容的问题。3.7.7 原有旧审批界面并不能接收新版服务器请求；3.7.8 同时接入新旧协议。

“继续未完成部分”会要求 Hermes 先检查之前已经改过的记录，只补齐欠缺部分。Markdown 和 JSON 仍不是一个原子事务，因此中断后仍需核对实际结果。App 不会自动关闭审批或替你批准。

如果仍卡住，打开“查看处理详情”，保留包含具体错误的消息或截图。如果是连接失败，请同时保留“连接诊断”中的记录；审批错误和网络错误需要分别定位。

如果旧版操作记录已被清除，无法出现续做按钮，可在原“处理评论数问题选择”对话中发送下面这段话：

请继续刚才未完成的卡片同步，沿用本对话原 today-card-action.json 的 operation_id 和我的原选择。先检查挂起清单.md、当前 hermes-today.json 和 action_receipts，已完成的清单修改不要重复，只补齐未完成的 JSON 与匹配回执。若记录存在后续变化或原操作编号找不到，先说明，不猜测覆盖。需要审批时正常向客户端发起请求，等待我确认，不要关闭审批或改用其他方式绕过审批。使用约定 writer 写入并回读后，再报告哪些修改已确认。
