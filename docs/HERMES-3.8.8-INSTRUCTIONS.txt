Hermes Android 3.8.8 · 安装与使用

一、安装
直接覆盖安装 Hermes-Android-3.8.8-release.apk，不用卸载。
版本 3.8.8 / 388，沿用 com.qingyu.hermescompanion.preview 和原签名，保留连接与本地设置。

二、本次更新
1. 深度助理首页右上角更换为头胸部人物，脸部和表情更清楚。
2. 6 段透明动作自动轮播，动作之间停留 1–3 秒。轻柔动作较多，转头、眨眼偶尔穿插。
3. 点一下人物，她会眨眼回应，然后回到轮播；连续点按不会不断重播。
4. 人物滑出可见区域、离开首页或 App 进入后台时停止播放。
5. 开启“减少动态效果”或系统关闭动画时显示静态形象。Android 8 继续使用静态后备图。

动画在本机播放，不用网络，不创建 Agent 对话，也不代表 Agent 当前的执行状态。
简洁首页继续保留原来的大尺寸人物和布局。

三、原配置继续使用
保留 3.8.7 的卡片完成后自动核对首页、自然事项聊天、手动重命名和首页信息区。
首页设置、早晚整理和文件收纳都不用重做；服务器不需要更新。

四、上传 OSS
Bucket：hermes-app-releases-jerome
目录：releases/

1. 先上传 Hermes-Android-3.8.8-release.apk，保留文件名。
2. 确认可下载：https://download.leaier.com/releases/Hermes-Android-3.8.8-release.apk
3. 再上传并覆盖 android-latest.json（versionName=3.8.8，versionCode=388）。
   如果下载后 JSON 文件名带数字后缀，上传时改回 android-latest.json。
4. 元数据地址：https://download.leaier.com/releases/android-latest.json
5. 手机“我的 → 设置 → 软件更新 → 检查更新”。

JSON：Content-Type: application/json; charset=utf-8
Cache-Control: no-cache, max-age=0, must-revalidate
APK：Content-Type: application/vnd.android.package-archive
Cache-Control: public, max-age=31536000, immutable

只上传 APK 和 JSON，不上传源码或密钥；保留旧 APK。

五、安装后体验
打开深度助理首页，观察一轮自然动作；点人物确认眨眼结束后继续轮播。
切换三套外观、浅色/深色，确认没有黑底、灰底或明显裁切。
滚动使人物离屏、切换页面、锁屏再回来，确认播放正常恢复。
在外观中开启“减少动态效果”，确认人物保持静止。

构建环境与模拟设备已验证；实际手机的流畅度与厂商后台行为需安装后体验。
