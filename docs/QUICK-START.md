# Hermes Android 快速开始

适用于 **3.8.8**。先把手机连接到自己的 Hermes，再决定是否启用事项首页。

## 1. 安装并连接

安装 `Hermes-Android-3.8.8-release.apk`，Android 8.0 及以上可用。同包名、同签名旧版可直接覆盖安装，不需要卸载。

完成或跳过欢迎动画，设置手机端昵称与头像，然后输入电脑端使用的完整远程 URL、Hermes 用户名和密码。地址不要额外添加 `/api` 或 `/v1`；如果原地址带反向代理路径前缀，保留该前缀。连接失败时先确认手机能访问服务器，再使用连接页的诊断入口；详见 [远程网关接入](SERVER_SETUP.md)。

App 需要已有 Hermes Agent 和远程网关；它本身不在手机上运行模型。登录密码不保存，Cookie 在本机加密保存。

## 2. 直接开始使用

新用户默认进入**简洁首页**。点“跟我说”继续固定的日常对话；独立话题可从“回看”新建对话。“任务”查看执行、定时安排和待确认操作，“文件”浏览服务器工作区，“我的”管理设置。

在对话中点击“＋”添加资料，或从其他安卓应用分享文字、链接、图片和文件到 Hermes。资料会先进入发送准备界面，检查后再发送。语音输入、连续语音和朗读可在语音设置中配置。

想给对话起一个好找的名字：进入“回看”的对话操作菜单，选择“重命名”，手动输入并保存，最多 120 个字符。

## 3. 按需启用深度助理

首页右上角 **齿轮 → 首页模式 → 深度助理**。这只是切换显示方式；首次整理与定时整理均由你主动配置。

| 设置 | 操作与后续使用 |
| --- | --- |
| 首次整理 | 没有首页内容时点击“开始首次整理”，等待 Hermes 根据现有资料生成首页。已有内容后不再显示这个按钮。 |
| 早晚整理（可选） | 设置时间和时区，保存后核对实际任务状态及下一次执行时间。配置一次即可持续运行，以后需要改时间再进来。 |
| 文件收纳 | 仅旧版用户尚未迁移时显示按钮；把概览、锁和快照收进 `.hermes-app/today/`，原业务文件留在原处。新用户不需要做这一步。 |

处理卡片时可以直接选择、填写，也可以进入对话说明进展。在卡片对话中每轮回复结束后，App 会核对该事项的最新记录并自动同步首页；核对或写回失败会保留状态，方便继续检查，不会把点击或普通讨论当成完成。

已有首页、文件收纳和早晚整理配置不需要因升级到 3.8.8 重做。齿轮中的维护工具用于排查或修复，不是日常必点项目。

## 常见问题

**不想使用事项首页，能一直用简洁首页吗？**

可以。在首页齿轮切回即可，App 会记住选择。已有文件与对话保留；如果以前配置过早晚整理，切换首页不会暂停服务器任务，需要到“任务”中单独暂停。

**为什么首次整理和文件收纳没有按钮？**

已有首页内容时无需再次首次整理。文件已收纳，或新用户还没有旧文件时，也无需迁移；页面会解释当前状态。

**自动任务的对话去了哪里？**

手机把 App 自动整理、刷新和处理记录放在“任务”里，普通列表主要显示主动聊天。服务器与 PC 端记录仍保留，当前版本不会自动销毁服务器对话。

**在其他端处理完授权，手机仍有提醒怎么办？**

在授权窗口点击状态核对，等待页面显示核对结果。新版网关确认请求已处理后会移除提醒；旧网关无法确认时，窗口提供明确确认后的本机移除方式。移除本机提醒不等于向服务器允许执行。

**为什么人物没有动？**

3.8.8 的新头胸部形象位于深度助理右上角，会自然轮播，点一下可眨眼。离屏、后台、开启减少动态效果或系统关闭动画时暂停；Android 8 使用静态形象。简洁首页保留原来的大尺寸人物。

**如何更新 App？**

进入“我的 → 设置 → 软件更新”。手机更新依赖维护者发布的 APK 和更新元数据，GitHub 代码更新不会自动替代 OSS 上传。覆盖安装需保持包名和签名一致。
