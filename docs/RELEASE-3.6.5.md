# Hermes 3.6.5

本版优化助理首页的人物比例、日期展示和随机短句。本次同版本修订进一步缩小对话右上角菜单。

| 修改 | 使用效果 |
| --- | --- |
| 温暖灵动人物布局 | 按左侧问候语与“跟我说”按钮确定人物展示高度，头顶对齐问候语顶部，脚底对齐按钮底部。去除素材透明边距带来的视觉偏移，保留互动动作所需空间。 |
| 日期和星期 | 三套皮肤左上角改为小字号日期与星期，例如“9月10日 · 星期四”；英文界面使用对应英文日期。随系统时间、时区和前台恢复更新。 |
| 随机短句 | 内置 48 组中英文短句，中文每条不超过 15 字，包含标点最多 11 字。重新进入首页或跨日时更换，避免连续重复；停留阅读、分钟刷新或切换主题时保持当前句子。 |
| 文案排版 | 短句最多展示两行，温暖主题保留固定两行高度，避免句子长短改变按钮和人物位置。有待确认事项或正在执行的任务时优先展示相关状态。 |
| 对话菜单（同版本修订） | 三套主题均改为按文字长度确定菜单宽度。中文常规字号宽度 128 dp，英文适当加宽；收小圆角，保留居中排版与 48 dp 点击行高。 |

短句示例：“把烦恼调成静音”“先喝口水，再拯救世界”“累了就歇会，太阳也下班”。短句保存在应用内，无需联网。

`Hermes-3.6.5.apk` 为 Release 构建，内部版本号 365。沿用 `com.qingyu.hermescompanion.preview` 和此前正式版的签名，支持覆盖安装同签名的 3.6.4 或 3.6.5 初版，保留原有配置。版本名称与内部版本号保持不变。

证书 SHA-256：`741c1844bb9267547e06af30d56c0da5bfcbf01491d3670496d88837a2860ad6`。

构建环境为 JDK 21、Gradle 8.13、Android SDK / Build Tools 36；源码不包含签名私钥或构建缓存。

```sh
./gradlew -PhermesPreview=true -PhermesSigningFile=/absolute/path/to/hermes-preview.keystore :app:assembleRelease
```
