# Hermes Android 3.8.8

2026-10-05，基于完整 3.8.7 源码。版本 3.8.8 / 388，沿用原包名和证书覆盖安装。

## 首页人物

深度助理首页右上角改为头胸部形象，保留白发、蓝灰色眼睛、耳机与原有服装。显示区域仍为 76 × 82dp，使用完整的新构图，不再套用旧半身动画的身体裁切参数。三套外观、浅色与深色模式共用透明人物。

采用用户提供的 1、2、3、5、6、7 号视频；4 号解码后的画面与 3 号完全相同，不重复打包。视频统一去除黑色或灰色背景、移除音轨，并转换为本地透明 Animated WebP。6 段片头片尾接回共同的静态姿势，短过渡采用预乘透明度混合。原视频中不同的转头角度保留，不做倒放。素材仅用于自然陪伴，不表示 Agent 当前真实工作状态。

## 播放规则

- 每轮随机排列呼吸、招呼、倾听、点头四段轻柔动作，再交替加入转头或眨眼；跨轮避免连续重复。
- 每段结束后保持共同姿势 1–3 秒，再播放下一段。
- 点按人物优先播放眨眼，播放期间重复点按不会重启或排队。结束后继续自动轮播。
- 离屏、离开页面、App 后台时停止动画和等待计时。重新可见时从共同姿势开始下一段。
- 减少动态效果、系统关闭动画，以及 Android 8 使用静态形象。动画解码失败回退静态并继续调度，结束回调异常还有有界超时保护。
- 过期动画回调通过代次标识丢弃，避免切换、点击或退后台后错误推进播放。

这些动作在手机本地播放，不调用 Agent，不创建会话，不需要服务器配置。

## 兼容范围

简洁首页继续使用原来的大尺寸人物和三套布局。3.8.7 的卡片自动同步、自然聊天、手动改名、首页信息区及既有首页配置全部保留。本次不修改持久首页协议、writer、Cron 或服务器逻辑。

## 素材维护

`tools/prepare_home_portraits.py` 可从本次原始编号视频重建素材。需要 ffmpeg、Pillow、numpy、scipy。参数为输入目录和输出目录；`--preview` 生成用于检查边缘的分析图。转换针对这组固定机位的单人头胸部素材，不是通用视频抠像工具。

资源清单、原视频 SHA-256、成品大小与时长见 [portrait-assets-3.8.8.json](portrait-assets-3.8.8.json)。打包不包含原 MP4 或音轨。验证结果见 [VALIDATION-3.8.8.md](VALIDATION-3.8.8.md)。
