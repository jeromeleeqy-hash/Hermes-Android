# Hermes workspace/file icons — refined round 04

This visual round covers Space, file types, source conversation and document
actions. It does not modify application code.

Included semantics:

- Navigation: recent artifacts, project files, open folder.
- File types: folder, Markdown, image, HTML/web and generic file.
- Context: source conversation and preview.
- Document actions: edit, save, copy path, share, save to phone and delete.

Interaction and visual decisions:

- File type is expressed by one closed glyph in a quiet color well.
- “Source conversation” uses a single closed chat outline; it is not assembled
  from overlapping bubbles and therefore has no broken tail or crossing line.
- Blue is navigation/context, green is Markdown/save, violet is image, amber is
  folder, and red is reserved for deletion.
- The primary document action is Edit or Save. Copy, share and download remain
  compact secondary actions.
- Every icon is audited at 24 px actual size.

Vector geometry is derived from Phosphor Icons Core 2.1.1 (MIT):
<https://github.com/phosphor-icons/core>
