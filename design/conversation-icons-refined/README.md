# Hermes conversation icons — refined round 02

This round covers the highest-frequency conversation actions and validates them
inside three real UI contexts: the chat top bar, the minimal message composer,
and the home search/compose actions.

Key decisions:

- Professional closed compound-path masters; no manually layered strokes.
- Regular optical weight at 24 px for calm default actions.
- Filled state only where state actually changes: microphone, send, assistant,
  and completion.
- The default composer exposes only attachment and microphone/send.
- Commands move into the attachment tray; live voice and assistant stay in the
  top bar.
- Hermes blue `#2A9FE8`, cyan `#28C7BE`, and success green `#25BF91`.

Vector geometry is derived from Phosphor Icons Core 2.1.1 (Apache-2.0):
<https://github.com/phosphor-icons/core>

This is a visual proposal only. No application code is changed in this round.
