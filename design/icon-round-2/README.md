# Hermes 图标第二轮视觉方向

本轮仅做视觉方案，不修改 App 代码。

## 对 Telegram 图标语言的拆解

- 底栏使用同一光学中心的“线性 / 实体”双状态，切换时不会出现图形跳动。
- 线性图标依赖完整的负形，而不是把两条完整轮廓直接叠在一起；相交对象需要遮挡、断开或前后层级。
- 24 × 24 网格内统一约 1.8 px 线宽，圆头、圆角连接，避免局部突然变粗。
- 未选中图标使用中性灰，选中图标使用品牌蓝和实体轮廓，色彩只承担状态提示。
- 设置页采用高饱和渐变圆角底块与白色简洁符号；不同色相区分类别，但所有符号共享同一尺寸、重量和留白。

## Hermes 方案

- 对话：保留双气泡语义，但后方气泡只显示可见部分，消除线条穿插。
- 空间：改为“前景内容卡 + 后景卡片”，前景轮廓遮挡后景，表达文件与产物集合。
- 任务：用稳定的三行节奏表达检查清单，线性和实体状态保持同一基线。
- 我的：头像与肩部轮廓使用开放式底边，实体态简化为稳定的人形剪影。
- 设置图标：远程网关、外观、通知、语音、模型、审批、归档等统一采用白色符号和高饱和渐变色块。

## 动效建议

- 底栏状态切换：180–220 ms，线性图标淡出并缩放到 0.94，实体图标同步淡入至 1.0。
- 选中背景滑块继续保留，但按钮自身不出现灰色 Ripple 遮罩。
- 图标、文字和选中背景共用同一缓动曲线，避免分段启动。

- `02_bottom_navigation_preview`：放入首页与底栏后的视觉效果。
- `03_settings_preview`：设置页图标的完整列表效果。
