# Hermes profile and settings icons — refined round 06

This visual round covers the Profile home, the separate Settings page, and
Hermes Agent file shortcuts. It does not modify application code.

Included semantics:

- Profile actions: set photo, edit info and settings.
- Connection and preferences: gateway, appearance, notifications and voice.
- Agent configuration: skills and tools, models, chat style, approval, and
  memory/context.
- Library and support: archived chats, changelog, user guide and About Hermes.
- Direct Agent files: Memory and Soul.

Interaction and visual decisions:

- The Profile home contains identity and three primary actions. Settings opens
  a dedicated page that does not repeat the avatar or profile information.
- Memory and Soul are direct file-viewer entries, not settings shortcuts.
- Default controls use neutral outlines; filled glyphs are reserved for active
  states and compact colored wells.
- Blue indicates navigation/connection, cyan indicates voice/conversation,
  violet indicates Agent capability and Soul, and green indicates verified or
  approved state.
- The avatar should use a shared-element transition into the full-photo view.
- Every icon is audited at 24 px actual size.

The package includes 18 outline SVGs and 18 filled SVGs.

Vector geometry is derived from Phosphor Icons Core 2.1.1 (MIT):
<https://github.com/phosphor-icons/core>
